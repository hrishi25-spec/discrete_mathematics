02 Basic Counting: Sum/Product Rule, Permutations, Combinations, Repetition, Stars and Bars

1. Why this topic matters

Basic counting is the engine behind almost every later topic: partitions, Stirling numbers, derangements, and graph enumeration all start with these rules. The key skill is recognizing whether order matters, whether repetition is allowed, and whether objects or containers are distinguishable. A wrong choice of formula by one word changes the answer by orders of magnitude.

2. Prerequisites

Set notation and basic sets from page 01: membership, subsets, union/intersection, and the idea of a function. You also need factorials: n! = n·(n−1)···1, with the convention 0! = 1. Nothing else is assumed.

3. Intuition

Every counting question on this page is one question in disguise: am I choosing a sequence or a set? If the order of the choices is visible in the answer (a PIN, a seating order), count sequences: multiply the choices position by position. If the order is invisible (a committee, a bag of fruit), count sets: either pick all at once with C(n,r), or count ordered picks and divide by the number of orders you over-counted. Repetition is a separate switch: with repetition each position may reuse a value, and for unordered picks the repetition turns the problem into dropping r identical items into n labelled boxes. The picture shows the product rule on a real object: 3 shirts and 2 pairs of trousers give 6 outfits, one cell per outfit.

What to notice: the grid has 3·2 cells because the shirt and the trousers are chosen independently. Try this: add a third pair of trousers and check that the grid gains exactly 3 new cells, not 1.

4. Definitions

Rule of sum. If a set of outcomes is the union of disjoint cases X and Y with |X| = x and |Y| = y, then the number of outcomes in X or Y is x+y. Disjoint is essential; overlapping cases must be corrected (that is inclusion–exclusion, page 04).

Rule of product. If a task is performed by first choosing one of x options and then, independently, one of y options, the task has xy outcomes. "Independently" means every option at the second stage is available whatever was chosen at the first; if the second-stage count changes with the first choice, split into cases and add.

Factorial. n! = n(n−1)···2·1 for n≥1, and 0! = 1 (one empty ordering).

Permutation, P(n,r). An ordered arrangement of r distinct objects chosen from n distinct objects. Also written nPr or (n)r. For r=n this is n!.

Combination, C(n,r) or (n choose r). An unordered selection of r distinct objects from n, i.e. an r-element subset. C(n,r) = n! / [r! (n−r)!].

Multiset (redundant combination). A selection of r objects from n types in which repetition is allowed and order is irrelevant. It is the same data as a list of counts (y1,…,yn) with each yi≥0 and y1+…+yn=r.

Stars and bars. The picture for that count: r identical stars (the chosen items) separated by n−1 bars (the walls between types). A weak composition of r into n parts is exactly such a solution with yi≥0.

Composition. A way of writing n as an ordered sum of positive integers, e.g. 7 = 3+1+2+1. Order matters: 3+1+2+1 and 1+3+1+2 are different compositions.

Circular arrangement. A seating of n distinct people around a round table, where seatings that differ only by a rotation are the same plan.

Combinatorial (bijective) proof. A proof that two counts are equal by exhibiting a one-to-one correspondence between the objects being counted, instead of computing both formulas.

5. Theorems and complete proofs

The two counting rules are not proved from anything deeper; they are the axioms of this page, justified by disjointness and by independence.

  • Sum rule, why: if X and Y are disjoint, listing X then listing Y lists each outcome of X∪Y exactly once, so the list has x+y entries. If they overlap, the overlap is listed twice, which is the double-counting error in section 9.
  • Product rule, why: the pairs (a,b) with a∈X, b∈Y form a grid of x columns and y rows, and the grid has xy cells. This is exactly the picture in section 3.

Theorem 1: a set with n elements has 2n subsets

Exam likely. Count the subsets of A = {a1,…,an}.

  1. Describe a subset by decisions. For each element ai the subset either contains it or does not. This gives an n-tuple of answers (in, out, in, …).
  2. The description is a bijection. Two different answer tuples differ at some ai, so they describe different subsets; and every subset produces exactly one tuple. Hence counting subsets is the same as counting answer tuples.
  3. Each decision has 2 options. The decision for ai is "in" or "out", and it is not restricted by the decisions made for the other elements.
  4. Apply the product rule. There are n independent decisions with 2 options each, so the number of tuples, hence of subsets, is 2·2···2 = 2n.
  5. Check the small cases. n=0 gives 20=1, the empty set only; n=3 gives 8 = ∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}. ∎

Theorem 2: n distinct objects can be arranged in n! orders

Exam likely.

  1. Build the arrangement left to right. An arrangement is a filling of n positions 1,…,n by the n distinct objects, each used once.
  2. Count position 1. Any of the n objects may go there: n options.
  3. Count position i. After positions 1,…,i−1 are filled, exactly i−1 objects are used, so n−(i−1) = n−i+1 objects remain and each is allowed.
  4. Apply the product rule. The number of fillings is n(n−1)(n−2)···2·1 = n!.
  5. No over-counting. A filling is the arrangement, so different choice sequences give different arrangements, and every arrangement arises from one sequence. ∎

Theorem 3: ordered selections, P(n,r) = n! / (n−r)!

  1. Reduce to a filling problem. An ordered selection of r distinct objects from n is a filling of r positions by distinct objects.
  2. If r > n the count is 0, because r distinct objects cannot be found in an n-element set. So assume 0≤r≤n.
  3. Count position by position. Position 1 has n options; after i−1 positions are filled, position i has n−i+1 options, for i=1,…,r.
  4. Apply the product rule. The count is n(n−1)···(n−r+1).
  5. Rewrite as a ratio of factorials. Multiply and divide by (n−r)!: n(n−1)···(n−r+1)·(n−r)! = n!, so the count is n!/(n−r)!.
  6. Order is part of the object, so nothing is identified: no division step is needed. For r=n this recovers Theorem 2. ∎

Theorem 4: unordered selections, C(n,r) = n! / [r! (n−r)!]

Exam likely.

  1. Start from the ordered count. By Theorem 3 there are P(n,r) ordered lists of r distinct objects.
  2. Forget the order. Map each ordered list to the r-element set of its entries. Every r-subset is hit, because any r-subset can be listed in some order.
  3. Count the lists over one fixed subset. Fix an r-subset S. The ordered lists that map to S are exactly the arrangements of the r elements of S, and by Theorem 2 there are r! of them.
  4. Double count. The lists split into fibres of size r!, one fibre per r-subset. Hence P(n,r) = r!·C(n,r).
  5. Divide. C(n,r) = P(n,r)/r! = n!/[r!(n−r)!]. For r>n or r<0 the value is 0. ∎

Theorem 5: C(n,r) = C(n,n−r)

  1. Define a map. For a subset S⊆A with |A|=n, let Sc = A\S be its complement.
  2. The map stays in the right family. If |S|=r then |Sc| = n−r, since S and Sc are disjoint and together make up A.
  3. It is injective. If Sc = Tc, then taking complements again gives S = T.
  4. It is surjective. Every (n−r)-subset U is the complement of the r-subset Uc.
  5. Bijection, so equal counts: the number of r-subsets equals the number of (n−r)-subsets. Algebraically the same identity follows by replacing r by n−r in Theorem 4. ∎

Theorem 6 (Pascal): C(n,r) = C(n−1,r−1) + C(n−1,r)

  1. Fix the ground set A = {1,2,…,n} and a size r with 1≤r≤n.
  2. Split the r-subsets by the element n. Case 1: the subset contains n. Case 2: it does not. These cases are disjoint and cover every r-subset, so the sum rule applies.
  3. Count case 1. If S contains n, then S\{n} is an (r−1)-subset of {1,…,n−1}. Conversely every such subset, with n added back, gives a valid S. This is a bijection, so case 1 has C(n−1,r−1) members.
  4. Count case 2. If S does not contain n, then S is an r-subset of {1,…,n−1}, so case 2 has C(n−1,r) members.
  5. Add. C(n,r) = C(n−1,r−1)+C(n−1,r). The boundary cases r=0 and r=n hold because C(n,0)=C(n,n)=1 and the missing terms are 0. ∎

Check: n=5, r=2 gives C(5,2)=10 = C(4,1)+C(4,2) = 4+6.

Theorem 7: C(n,0)+C(n,1)+…+C(n,n) = 2n

  1. Count the same objects two ways. Count all subsets of an n-element set.
  2. First way. By Theorem 1 there are 2n subsets in total.
  3. Second way. Classify each subset by its size k. The classes for k=0,1,…,n are disjoint and cover all subsets, so by the sum rule the total is C(n,0)+C(n,1)+…+C(n,n).
  4. Equate. Both counts count all subsets, so the sum equals 2n.
  5. Independent check. Put x=y=1 in the binomial theorem (Theorem 8): (1+1)n = Σk C(n,k). ∎

Check n=4: 1+4+6+4+1 = 16 = 24. The lecture's statement of this identity omits the C(n,2) term; the correct sum contains every k from 0 to n (see the box below).

Theorem 8 (binomial theorem): (x+y)n = Σk=0n C(n,k) xkyn−k

  1. Write the power as a product. (x+y)n is the product of n identical factors (x+y).
  2. Expand without collecting. Choosing one of the two terms from each factor gives 2n raw terms (Theorem 1 again), each a product of n letters, some x and some y. The order of the letters does not matter because multiplication commutes.
  3. Identify the monomial. A raw term equals xkyn−k exactly when x was chosen from k of the n factors (and y from the other n−k).
  4. Count the terms with that monomial. Choosing which k factors supply x is choosing a k-subset of the n factors, so there are C(n,k) such raw terms (Theorem 4).
  5. Collect. Adding those C(n,k) equal terms gives the coefficient C(n,k) on xkyn−k. Summing over k=0,…,n gives the formula. It holds for all real x,y and all n≥0. ∎

Check n=3: (x+y)3 = x3+3x2y+3xy2+y3, and the coefficients are C(3,0),C(3,1),C(3,2),C(3,3) = 1,3,3,1.

Theorem 9 (Vandermonde): C(n+m,r) = Σk C(n,k) C(m,r−k)

  1. Set up two groups. Let A have n elements and B have m disjoint elements. Count the r-subsets of A∪B; by Theorem 4 there are C(n+m,r).
  2. Classify by how many elements come from A. Let k be the number of chosen elements lying in A. Then 0≤k≤r, and the remaining r−k chosen elements lie in B. The classes for different k are disjoint and cover all r-subsets.
  3. Count one class. Choose the k elements from A in C(n,k) ways and, independently, the r−k elements from B in C(m,r−k) ways. By the product rule the class has C(n,k)C(m,r−k) members (terms with k>n or r−k>m are 0).
  4. Add the classes. The sum rule gives Σk C(n,k)C(m,r−k).
  5. Equate the two counts. Setting r=n and using Theorem 5 on C(m,n−k) gives the symmetric form C(n+m,n) = Σk C(n,k)C(m,k) quoted in the lecture. ∎

Check n=2, m=3, r=2: C(5,2)=10 and C(2,0)C(3,2)+C(2,1)C(3,1)+C(2,2)C(3,0) = 3+6+1 = 10.

Theorem 10: redundant permutations, nr

  1. The object. A length-r word over an alphabet of n letters, repetition allowed, is fixed by its r positions.
  2. One position at a time. Position 1 may hold any of the n letters. Position 2 may again hold any of the n letters, because repetition is allowed and earlier choices do not remove letters.
  3. Independence. Every position has exactly n options regardless of the other positions, so the product rule applies with r factors.
  4. Result. n·n···n (r factors) = nr. Each word arises from exactly one choice sequence, so there is no over-counting. ∎

Theorem 11 (stars and bars): the number of multisets of size r from n types is C(n+r−1,r)

Exam likely. Equivalently, the number of nonnegative integer solutions of y1+…+yn=r.

Proof A (bar positions).

  1. Encode a solution as a picture. Given (y1,…,yn), draw y1 stars, then a bar, then y2 stars, then a bar, …, then yn stars. There are n−1 bars and r stars, so the picture has r+n−1 symbols.
  2. The picture determines the solution. Reading the stars between consecutive bars recovers y1,…,yn, so the encoding is injective. Conversely any placement of n−1 bars among r+n−1 positions gives some solution, so it is surjective. It is a bijection.
  3. Count the pictures. A picture is determined by the set of the n−1 positions that hold bars, chosen from r+n−1 positions. By Theorem 4 there are C(r+n−1,n−1) of them.
  4. Use Theorem 5. C(r+n−1,n−1) = C(r+n−1,r), because (r+n−1)−(n−1) = r.
  5. Conclusion. The number of multisets, and of nonnegative solutions, is C(n+r−1,r). For r=0 this gives 1 (choose nothing), which is correct. ∎

Proof B (strictification, the lecture's bijection).

  1. Write a multiset as a sorted list. A multiset of size r from {1,…,n} is the same as a nondecreasing list 1≤a1≤a2≤…≤ar≤n: sort the chosen values, repetitions included.
  2. Strictify. Define bi = ai+i−1. Then bi+1−bi = (ai+1−ai)+1 ≥ 1, so the b-list is strictly increasing.
  3. Bounds. b1 = a1 ≥ 1 and br = ar+r−1 ≤ n+r−1. So (b1,…,br) is an r-subset of {1,…,n+r−1}.
  4. It is a bijection. The inverse is ai = bi−i+1, which is nondecreasing because b is strictly increasing and stays in [1,n]. So the map between multisets and r-subsets is one-to-one both ways.
  5. Count the subsets. There are C(n+r−1,r) r-subsets of an (n+r−1)-element set, hence the same number of multisets. ∎

Check n=4 types, r=7 items: C(10,7) = C(10,3) = 120, matching the enumeration of 7 chocolates into 4 kids in example 5.

Theorem 12 (compositions): the number of compositions of n into exactly r positive parts is C(n−1,r−1)

  1. The object. A composition is a solution of a1+…+ar=n with every ai a positive integer; the order of the parts is part of the object.
  2. Take partial sums. Define si = a1+…+ai for i=1,…,r−1, and set s0=0, sr=n.
  3. Where the partial sums live. Since each part is ≥1, 1≤s1<s2<…<sr−1≤n−1. So the interior partial sums form an (r−1)-subset of {1,…,n−1}.
  4. The map is a bijection. Different compositions have different partial sums, and any (r−1)-subset 1≤s1<…<sr−1≤n−1 produces the positive parts ai=si−si−1 (with sr=n) summing to n.
  5. Count. There are C(n−1,r−1) such subsets, hence that many compositions. Boundary cases: r=1 gives C(n−1,0)=1 (the single part n); r>n gives 0 since n cannot be split into more than n positive parts. ∎

This is also the count of ways to put n identical balls into r distinct boxes with no empty box, since yi≥1 is the same as ai=yi. Check n=7, r=4: C(6,3)=20, matching the four orderings of 4+1+1+1, twelve of 3+2+1+1 and four of 2+2+2+1.

Theorem 13: n distinct people can sit around a round table in (n−1)! ways

  1. Start with line arrangements. Put the n people in a row: by Theorem 2 there are n! ways.
  2. Roll the row into a circle. Place the row around the table in order, starting at a fixed seat. This produces a circular seating.
  3. Count the rows per circle. Cutting the same circle open at each of its n seats gives n different rows, and these are distinct because the people are distinct. Conversely every row whose circular plan is this circle is one of those cuts. So each circular plan is produced by exactly n rows.
  4. Divide. The number of circular plans is n!/n = (n−1)!.
  5. Small cases. n=1: 0!=1 (only one seat). n=2: 1!=1, since the two people are neighbours either way. n=5: 4!=24, not 5!=120. ∎

6. Worked examples

Example 1 (easy): 3-letter words over 26 letters, repetition allowed

Each of the 3 positions independently holds one of 26 letters. By the product rule (Theorem 10 with n=26, r=3) the count is 26·26·26 = 263 = 17576. Repetition is allowed, so "aaa" is legal; no division is needed because the positions are distinguishable.

Example 2 (easy): a committee of 4 from 10 people

Swapping two members gives the same committee, so order does not matter and repetition is impossible. By Theorem 4 the count is

C(10,4) = 10!/(4!·6!) = (10·9·8·7)/(4·3·2·1) = 5040/24 = 210.

If instead the four people were given the distinct roles chair, secretary, treasurer, member, the answer would be P(10,4) = 10·9·8·7 = 5040, i.e. 210·4!.

Example 3 (easy): 7 fruits from 4 types, order irrelevant, repetition allowed

This is a multiset of size r=7 from n=4 types, so Theorem 11 gives C(7+4−1,7) = C(10,7) = C(10,3) = 120. In star-and-bar form one solution is ★★★|★||★★★, meaning 3 of type 1, 1 of type 2, 0 of type 3, 3 of type 4.

Sanity check: if we also cared which fruit was picked first, the count would be 47 = 16384, which is much larger; forgetting the order is what collapses it to 120.

Example 4 (medium): nonnegative solutions of x1+x2+x3+x4+x5=10

This is Theorem 11 with n=5 variables and r=10:

C(10+5−1,10) = C(14,10) = C(14,4) = (14·13·12·11)/(4·3·2·1) = 24024/24 = 1001.

Each solution is exactly one arrangement of 10 stars and 4 bars, so the picture has 14 symbols and we choose the 4 bar positions.

Example 5 (medium): 7 identical chocolates among 4 distinct kids

Empty boxes allowed. Each distribution is a solution of y1+y2+y3+y4=7 with yi≥0, so the count is C(7+4−1,3) = C(10,3) = 120. A brute-force enumeration of all 4-tuples of nonnegative integers summing to 7 confirms 120.

No kid empty. Put one chocolate in each kid's hand first, leaving 3 to distribute freely: yi≥1 becomes zi=yi−1≥0 with z1+…+z4=3, so the count is C(3+4−1,3) = C(6,3) = 20. Equivalently, Theorem 12 with n=7, r=4. The lecture's transformation "add 0,1,2,…,6 to the seven chocolates" is the same strictification bijection and gives C(10,7)=120 for the empty-allowed case.

Example 6 (medium): n married couples in a line, alternating man–woman

There are n men and n women, all distinct, and the line must alternate genders. Two readings of the question:

  • Reading A — the pattern starts with a man (M W M W …). Then the n men occupy the odd positions in n! orders (Theorem 2) and the n women occupy the even positions in n! orders, independently. Product rule: (n!)2.
  • Reading B — either gender may start. Reading A covers the patterns starting with a man; the patterns starting with a woman are another (n!)2, and the two families are disjoint. Sum rule: 2(n!)2.

Brute force for n=2 (2 men, 2 women, all alternating lines) gives 8 = 2·(2!)2, and for n=3 it gives 72 = 2·(3!)2. So unless the question fixes who starts, the safe answer is 2(n!)2; state the convention you use.

Example 7 (medium–hard): 4-letter words with no repeated letter

Position 1 has 26 choices, position 2 has 25 (the letter used is gone), position 3 has 24, position 4 has 23:

P(26,4) = 26·25·24·23 = 358800.

Consistency check with Theorem 4: choose the 4 letters first in C(26,4) = 14950 ways, then order them in 4! = 24 ways. Product: 14950·24 = 358800. ✔

Example 8 (hard): 5-card hands with exactly 3 hearts

A standard 52-card deck has 13 hearts and 39 non-hearts. Build the hand in two independent stages:

  • choose the 3 hearts: C(13,3) = (13·12·11)/(3·2·1) = 1716/6 = 286;
  • choose the 2 non-hearts: C(39,2) = (39·38)/2 = 1482/2 = 741.

Product rule: 286·741 = 211926 hands. Check the size of the answer: the total number of 5-card hands is C(52,5) = 2598960, and 211926 is a plausible fraction of it (about 8.2%). The two stages are independent because the heart and non-heart pools are disjoint.

9. Common mistakes and exam traps

  1. Using nr when the order does not matter. Wrong: "3 scoops from 5 flavours" = 53 = 125 (that counts ordered scoops). Right: C(5+3−1,3) = C(7,3) = 35 multisets.
  2. Using C(n,r) when repetition is allowed. Wrong: C(5,3) = 10. Right: C(7,3) = 35. The 25 missing selections are the ones that reuse a flavour.
  3. Wrong bottom number in stars and bars. For 7 fruits from 4 types, wrong: C(10,4) = 210. Right: C(10,3) = C(10,7) = 120. The bar count is n−1 = 3, so the bottom number is 3 (or equivalently 7), never 4.
  4. Forgetting that "at least one" subtracts first. For x1+…+x4=7 with every xi≥1, wrong: C(10,3)=120 (that allows zeros). Right: give one to each variable, then distribute the remaining 3: C(6,3)=20.
  5. Using n! for a circle. Wrong: 5 people around a table = 5! = 120. Right: (n−1)! = 4! = 24, because the 5 rotations of a seating are one plan.
  6. Forgetting that a leading zero is not allowed. Wrong: 4-digit numbers = 104 = 10000. Right: 9·103 = 9000 (first digit 1–9, then any of 10 digits three times).
  7. Dividing by r! when the objects repeat. Wrong: arrangements of AAB = 3! = 6. Right: 3!/2! = 3, namely AAB, ABA, BAA; the two A's are indistinguishable, so each arrangement was counted 2! times.
  8. Losing the factor 2 in alternating lines. Wrong: n couples alternating = (n!)2 always. Right: 2(n!)2 unless the question fixes who starts; for n=2 the two answers are 4 and 8, and brute force gives 8.
  9. Adding overlapping cases. Wrong: numbers ≤10 divisible by 2 or 3 = 5+3 = 8. Right: 5+3−1 = 7, because 6 was counted twice (inclusion–exclusion, page 04).

10. Practice questions (assigned to this page)

Q5. A president, vice-president, secretary and treasurer are selected from 11 people; the same person may hold more than one office. In how many ways?

Reading the question. The four offices are distinct roles, so the result is an ordered 4-tuple of people. The clause "the same person may hold more than one office" removes the distinctness condition, so repetition is allowed.

Step 1. President: 11 candidates.

Step 2. Vice-president: again 11, because the president may be chosen again.

Step 3. Secretary: again 11. Step 4. Treasurer: again 11.

Step 5. The four choices are independent (no choice removes a candidate), so the product rule applies: 11·11·11·11 = 114 = 14641.

Contrast. If one person could hold at most one office, the answer would be P(11,4) = 11·10·9·8 = 7920, because each choice would remove one candidate. The difference 14641−7920 = 6721 is exactly the assignments that reuse a person.

Check. 112=121, 1212=14641, so 114=14641. A brute-force count of all 4-tuples from 11 people gives 14641.

Q21. Two numbers are equivalent if one is a digit permutation of the other. How many non-equivalent 4-digit numbers are there?

Not in slides — standard result. The count uses only the multiset formula of Theorem 11; the equivalence-class framing is the page-01 dictionary (relation ↔ partition).

Step 1 — identify the classes. Two 4-digit numbers are equivalent exactly when they contain the same multiset of four digits. So the answer is the number of distinct digit multisets that can produce at least one 4-digit number.

Step 2 — count all multisets of size 4 from 10 digits. By Theorem 11 with n=10 types and r=4: C(10+4−1,4) = C(13,4) = (13·12·11·10)/(4·3·2·1) = 17160/24 = 715.

Step 3 — remove the one multiset with no 4-digit member. The multiset {0,0,0,0} only produces 0000, which is not a 4-digit number. Every other multiset contains a nonzero digit; put that digit first and arrange the remaining three in any order, and you get a valid 4-digit number. Hence exactly one multiset is unusable.

Step 4 — subtract. 715 − 1 = 714 non-equivalent 4-digit numbers.

Check by brute force. Enumerating 1000,…,9999 and grouping by the sorted tuple of digits gives exactly 714 groups, so the class count and the "one representative per class" count agree. As a size check, there are 9000 four-digit numbers and 714 classes, an average of about 12.6 numbers per class, which is consistent: a class of four distinct nonzero digits has 24 members, one with a repeated digit fewer.

Second reading. If the question allowed leading zeros (counting 4-digit strings), the all-zero string would be legal and the answer would be C(13,4) = 715. The wording "4-digit numbers" rules that out, so the answer is 714.

11. Extra self-test questions

1. How many 4-digit PINs are there (digits may repeat)?

Four positions, each holding one of 10 digits, and repetition is allowed, so the product rule (Theorem 10) gives 10·10·10·10 = 104 = 10000. The PIN may start with 0, since it is a code, not a number.

2. In how many ways can 3 of 10 people be chosen for a committee?

Order is irrelevant and repetition is impossible, so Theorem 4 gives C(10,3) = (10·9·8)/(3·2·1) = 720/6 = 120. Equivalently P(10,3)/3! = 720/6.

3. In how many ways can 6 people sit around a circular table?

Theorem 13 with n=6: (n−1)! = 5! = 120. Start from the 6! = 720 line arrangements and divide by the 6 rotations of each circle: 720/6 = 120.

4. How many multisets of 7 fruits are there from 4 types?

Theorem 11 with n=4, r=7: C(7+4−1,7) = C(10,7) = C(10,3) = (10·9·8)/(3·2·1) = 120. Equivalently, count solutions of y1+y2+y3+y4=7; brute force gives 120.

5. How many nonnegative integer solutions does x1+x2+x3+x4=10 have?

Theorem 11 with n=4 variables and r=10: C(10+4−1,3) = C(13,3) = (13·12·11)/(3·2·1) = 1716/6 = 286. Each solution is one arrangement of 10 stars and 3 bars.

6. How many 5-card hands can be dealt from a 52-card deck?

A hand is an unordered 5-subset, so Theorem 4 gives C(52,5) = (52·51·50·49·48)/(5·4·3·2·1) = 311875200/120 = 2598960. Order of dealing does not matter: the 5! = 120 orders of the same hand are one hand.

7. How many 4-letter words use 4 different letters of the 26-letter alphabet?

Order matters and repetition is banned, so Theorem 3: P(26,4) = 26·25·24·23 = 358800. Cross-check with Theorem 4: choose the letters in C(26,4) = 14950 ways, then order them in 4! = 24 ways; 14950·24 = 358800.

8. How many compositions of 10 into exactly 4 positive parts are there?

Theorem 12 with n=10, r=4: C(10−1,4−1) = C(9,3) = (9·8·7)/(3·2·1) = 504/6 = 84. Direct check by brute force over positive 4-tuples summing to 10 gives 84.

12. Cheat sheet

Rules

  • Sum rule: disjoint cases add. Overlapping cases need inclusion–exclusion (page 04).
  • Product rule: independent stages multiply. If stage 2 depends on stage 1, split into cases and add.

Core formulas

  • Subsets of an n-set: 2n.
  • Permutations: n!; ordered r-selections: P(n,r) = n(n−1)···(n−r+1).
  • Unordered r-selections: C(n,r) = n! / [r! (n−r)!].
  • Multisets / nonnegative solutions: C(n+r−1,r) = C(n+r−1,n−1).
  • Positive solutions / compositions of n into r parts: C(n−1,r−1).
  • Lower bounds xi≥ai: set N′ = N−Σai and count nonnegative solutions of total N′, i.e. C(N′+n−1,n−1). If N′<0 the answer is 0.
  • Upper bounds xi≤ai: subtract the bad cases by inclusion–exclusion (page 04).
  • Circular arrangements of n distinct people: (n−1)!.
  • Alternating line of n couples: (n!)2 with a fixed starting gender, 2(n!)2 if either gender may start.
  • Arrangements of a multiset with repeats m1,…,mk: n!/[m1!···mk!].

Identities

  • C(n,r) = C(n,n−r) (complement bijection).
  • C(n,r) = C(n−1,r−1)+C(n−1,r) (Pascal).
  • Σk=0n C(n,k) = 2n.
  • (x+y)n = Σk C(n,k)xkyn−k.
  • Vandermonde: C(n+m,r) = Σk C(n,k)C(m,r−k); at r=n, Σk C(n,k)C(m,k).
  • Binomial rows: n=4: 1,4,6,4,1; n=5: 1,5,10,10,5,1; n=6: 1,6,15,20,15,6,1.

Exam checklist

  1. Does swapping two chosen items change the answer? Yes → order matters.
  2. May the same item be used twice? Yes → repetition allowed.
  3. Are the containers labelled? Labelled boxes → stars and bars; unlabelled → Stirling/partitions (page 03).
  4. Must every box be nonempty? Subtract one item from each first.
  5. Is a leading zero forbidden, or is the object a code? Codes may start with 0; numbers may not.
  6. Is the arrangement a circle? Divide the line count by n.
  7. Do the cases overlap? If so, do not just add.
