02 Basic Counting: Sum/Product Rule, Permutations, Combinations, Repetition, Stars and Bars

1. Why this topic matters

Basic counting is the engine behind almost every later topic: partitions, Stirling numbers, derangements, and graph enumeration all start with these rules. The key skill is recognizing whether order matters, whether repetition is allowed, and whether objects or containers are distinguishable. A wrong choice of formula by one word changes the answer by orders of magnitude.

2. Prerequisites

Set notation and basic sets from page 01.

3. Intuition

Counting is about independent choices. If a task splits into independent stages, multiply the number of choices at each stage. If it splits into disjoint cases, add the case counts. The picture below shows two independent choices: 3 shirts and 2 pants give 3×2=6 outfits.

4. Definitions

Rule of sum: if X and Y are disjoint events with x and y outcomes, then X or Y has x+y outcomes.

Rule of product: if X and Y are independent stages with x and y outcomes, then X and Y has xy outcomes.

Permutation: ordered arrangement of distinct objects.

Combination: unordered selection of distinct objects.

Redundant combination / multiset: selection with repetition allowed, order irrelevant.

Stars and bars: count nonnegative integer solutions y_1+...+y_n = r.

5. Theorems and complete proofs

Theorem: number of subsets

A set of n elements has 2^n subsets. Exam likely.

Proof. Each element is either in or out, giving 2 choices independently; product rule gives 2^n. ∎

Theorem: permutations of n distinct objects

n! = n(n−1)...1. Exam likely.

Proof. First position has n choices, then n−1, etc.; product rule gives n!. ∎

Theorem: ordered selections of r from n

P(n,r)=n!/(n−r)!.

Proof. First r positions have n,n−1,...,n−r+1 choices; product is n!/(n−r)!. ∎

Theorem: combinations

C(n,r)=n!/[r!(n−r)!]. Exam likely.

Proof. Each unordered r-set can be ordered in r! ways, so P(n,r)=r! C(n,r). ∎

Theorem: redundant permutations

If order counts and repetition is allowed, number is n^r.

Proof. Each of r positions independently chooses one of n types. ∎

Theorem: redundant combinations (stars and bars)

Number of multisets of size r from n types is C(n+r−1,r). Exam likely.

Proof. Let y_i be count of type i. Count nonnegative solutions y_1+...+y_n=r. Place r stars and n−1 bars in r+n−1 positions; choose positions of bars: C(n+r−1,n−1)=C(n+r−1,r). ∎

Theorem: binomial theorem

(x+y)^n = Σ_{k=0}^n C(n,k) x^k y^{n−k}.

Proof. Expanding (x+y)^n chooses x or y from each of n factors; to get x^k y^{n−k} choose which k factors give x: C(n,k) ways. ∎

6. Worked examples

Example 1

Number of 3-letter words over 26 letters with repetition allowed: 26^3=17576.

Example 2

Choose a committee of 4 from 10: C(10,4)=210.

Example 3

Number of multisets of 7 fruits from 4 types: C(7+4−1,4−1)=C(10,3)=120.

Example 4

Number of nonnegative solutions to x_1+...+x_5=10 is C(10+5−1,5−1)=C(14,4)=1001.

Example 5

Alternating line of n married couples: arrange men in n! ways and women in n! ways, giving (n!)^2.

9. Common mistakes and exam traps

  • Using n^r when order does not matter.
  • Using C(n,r) when repetition is allowed.
  • Forgetting that circular arrangements of n objects are (n−1)!.
  • Confusing C(n+r−1,r) with C(n+r−1,n).
  • Not checking whether containers/objects are distinguishable.

10. Practice questions (assigned to this page)

Q5. President, VP, secretary, treasurer selected from 11 people; same person may hold more than one office. Count?

Solution: 4 independent offices, each 11 choices: 11^4=14641. Python verification: 14641.

Q21. Two 4-digit numbers equivalent if one is a digit permutation of the other. How many non-equivalent 4-digit numbers?

Solution: equivalence classes correspond to multisets of 4 digits with at least one nonzero. Count = C(10+4−1,4)−1 = C(13,4)−1 = 715−1 = 714. Python verification: 714.

12. Cheat sheet

Sum rule: add disjoint cases; product rule: multiply stages.

Subsets: 2^n. Permutations: n!. Ordered selections: n!/(n−r)!.

Combinations: C(n,r). Redundant permutations: n^r.

Redundant combinations: C(n+r−1,r).

Circular arrangements: (n−1)!.

Binomial theorem: (x+y)^n=Σ C(n,k)x^k y^{n−k}.
