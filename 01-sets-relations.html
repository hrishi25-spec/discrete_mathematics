01 Sets, Relations, Equivalence Relations, Partitions, Functions, Sequences

1. Why this topic matters

Almost every counting and graph problem begins by deciding which objects are equivalent or how a set is partitioned. Equivalence relations turn messy "same for our purposes" ideas into clean buckets, and the theorem that they are exactly partitions is one of the first big structural results of the course. Functions and sequences then give the language for counting and recurrences later.

2. Prerequisites

None: this is the first topic. Review set notation (subset, power set, Cartesian product) as needed.

3. Intuition

Think of a set as a bag of objects and a relation as "linked." An equivalence relation is a link that is reflexive, symmetric, and transitive, so it behaves like "is in the same group as." The groups are the equivalence classes, and they partition the original set. The picture below partitions {1,2,3,4} into two groups.

4. Definitions

Set: a well-behaved collection of objects; subset, power set 2^A, Cartesian product A×B.

Binary relation R on A: R ⊆ A×A. Properties: reflexive (∀a, (a,a)∈R), symmetric ((a,b)∈R⇒(b,a)∈R), antisymmetric ((a,b),(b,a)∈R⇒a=b), transitive ((a,b),(b,c)∈R⇒(a,c)∈R).

Equivalence relation: reflexive + symmetric + transitive.

Equivalence class: [a]_R = {b∈A : (a,b)∈R}.

Partition of A: disjoint nonempty subsets whose union is A.

Function f:A→B: each a∈A has exactly one image in B; injective/surjective/bijective as usual.

Sequence: a function from a subset of N to a set S.

Composition of relations

If R1⊆A×B and R2⊆B×C, then R1∘R2={(x,z): ∃y∈B, (x,y)∈R1 and (y,z)∈R2}. Check textbook convention for order.

Russell's paradox

A={S: S∉S} leads to a contradiction; this motivated axiomatic set theory.

Partial and total orders

Partial order: reflexive + antisymmetric + transitive. The set is a poset.

Total order: partial order where every pair is comparable.

5. Theorems and complete proofs

Theorem: congruence modulo n is an equivalence relation

For n∈Z^+, define a~b iff n | (a−b). Exam likely.

Proof. Reflexive: n | (a−a)=0. Symmetric: if n | (a−b), then n | (b−a)=−(a−b). Transitive: if n | (a−b) and n | (b−c), then n | [(a−b)+(b−c)] = (a−c). ∎

Theorem: equivalence classes are disjoint or equal

If R is an equivalence relation on A, then for any a,b∈A, either [a]∩[b]=∅ or [a]=[b]. Exam likely.

Proof. Suppose [a]∩[b]≠∅ and take c in the intersection. Then a~c and b~c. By symmetry c~b, and by transitivity a~b. If x∈[a], then a~x; since a~b, transitivity gives b~x, so x∈[b]. Thus [a]⊆[b]; symmetrically [b]⊆[a]. ∎

Theorem: union of equivalence classes is A

∪_{a∈A}[a]=A. Exam likely.

Proof. Each [a]⊆A, so the union is ⊆A. Conversely every a∈A lies in [a] by reflexivity, so A⊆∪[a]. ∎

Theorem: equivalence relations correspond to partitions

If R is an equivalence relation on A, its classes form a partition of A. Conversely, any partition of A induces an equivalence relation whose classes are the blocks. Exam likely.

Proof. Forward: classes are nonempty by reflexivity, pairwise disjoint or equal by the theorem above, and their union is A. Backward: define a~b iff a,b lie in the same block; reflexivity, symmetry, and transitivity follow from "same block" being an equivalence on blocks. ∎

6. Worked examples

Example 1

Relation R on Z^+ by a~b iff a | b is reflexive and transitive but not symmetric (2|4 but 4∤2), so it is not an equivalence relation.

Example 2

Modulo 4 classes: [0]={...,-4,0,4,...}, [1]={...,-3,1,5,...}, [2], [3]. These four classes partition Z.

Example 3

Number of equivalence relations on a 3-element set equals Bell number B_3=5: partitions are 1+1+1, 2+1 (three choices of pair), 3.

Example 4

Number with exactly 2 classes on 6 elements is S(6,2)=2^5−1=31 (Python verified below).

Example 5

On {1,0.5,1/3,√2} all four elements are distinct objects, so equivalence relations depend only on cardinality 4: Bell number B_4=15.

9. Common mistakes and exam traps

  • Confusing antisymmetric with symmetric.
  • Forgetting that equivalence classes are nonempty and disjoint.
  • Thinking a partition's blocks can be empty.
  • Counting equivalence relations by 2^n instead of Bell/Stirling numbers.
  • Assuming [a]=[b] requires a=b; any member can represent a class.

10. Practice questions (assigned to this page)

Q1. How many equivalence relations on {1,...,6} have exactly 2 classes?

Solution: S(6,2)=2^{5}-1=31. Python verification: 31.

Q2. Is a~b iff 2 | (a+b) an equivalence relation on Z?

Solution: Yes. Reflexive since 2|2a; symmetric since sum commutes; transitive because if a,b have same parity and b,c have same parity then a,c have same parity. Classes are evens and odds.

Q3. How many equivalence relations on {α,β,γ}?

Solution: Bell number B_3=5. Python verification: 5.

Q11. How many equivalence relations with exactly 3 classes on a 5-element set?

Solution: S(5,3)=25. Python verification: 25.

Q25. How many equivalence relations on {1, 0.5, 1/3, √2}?

Solution: The set has 4 distinct elements, so Bell number B_4=15. Python verification: 15.

12. Cheat sheet

Equivalence relation = reflexive + symmetric + transitive.

Classes are disjoint or equal; their union is A.

Equivalence relations ↔ partitions.

Congruence mod n is an equivalence relation.

Counting relations with k classes: Stirling S(n,k).

Total equivalence relations on n elements: Bell B_n.

Any element can represent its class.
