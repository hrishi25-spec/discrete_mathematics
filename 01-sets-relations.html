01 Sets, Relations, Equivalence Relations, Partitions, Functions, Sequences

1. Why this topic matters

Almost every counting and graph problem begins by deciding which objects are equivalent or how a set is partitioned. Equivalence relations turn messy "same for our purposes" ideas into clean buckets, and the theorem that they are exactly partitions is one of the first big structural results of the course. Functions and sequences then give the language for counting and recurrences later. The counting questions on this page (how many equivalence relations with exactly k classes?) are answered by the Stirling numbers that page 03 develops, so this page is also where counting and structure first meet.

2. Prerequisites

None: this is the first topic. You should be comfortable with the following set notation, all of which is used below.

  • Membership and inclusion: x∈A, A⊆B, A=B means A⊆B and B⊆A.
  • Empty set: ∅ has no elements; ∅⊆A for every A.
  • Power set: 2^A (also written 𝒫(A)) is the set of all subsets of A; if |A|=n then |2^A|=2^n.
  • Cartesian product: A×B = {(a,b) : a∈A, b∈B}; if |A|=m and |B|=n then |A×B|=mn.
  • Set operations: union A∪B, intersection A∩B, difference A∖B, complement Aᶜ (relative to a fixed universal set).
  • Logic: ∀ ("for all"), ∃ ("there exists"), ⇒ ("implies"), ⟺ ("if and only if").

3. Intuition

Think of a set as a bag of objects and a relation as a collection of arrows between them. An equivalence relation is an arrow set with three habits: every object points to itself (reflexive), every arrow can be walked backwards (symmetric), and two arrows that meet head-to-tail can be replaced by one arrow (transitive). Those three habits force the objects into groups: inside a group everything points at everything, and between groups nothing points at all. Those groups are the equivalence classes, and they partition the original set. The first picture shows a partition as blobs; the second shows the same information as a digraph of the relation "same parity" on {1,2,3,4}.

What to notice: each vertex has a loop (reflexive), each edge is drawn in both directions (symmetric), and inside a group every pair is joined, so any two-step walk can be replaced by a one-step arrow (transitive). Try this: imagine removing the loop at 4 and check that "same parity" would stop being an equivalence relation.

4. Definitions

Set: a well-behaved collection of objects. A is a subset of B (written A⊆B) if every element of A is in B. The power set 2^A is the set of all subsets of A. The Cartesian product A×B is the set of ordered pairs (a,b) with a∈A, b∈B.

Binary relation from A to B: any subset R⊆A×B. When A=B, R is a relation on A. An n-ary relation is a subset of A1×⋯×An; relations of this kind are the mathematical model behind relational databases.

Equivalence relation: a relation that is reflexive, symmetric and transitive.

Equivalence class of a: [a]R = {b∈A : (a,b)∈R}. Read "[a] is the set of everything related to a".

Partition of A: a collection of pairwise disjoint, nonempty subsets (the blocks) whose union is A.

Function f:A→B: a relation f⊆A×B such that every a∈A has exactly one image f(a)∈B. It is injective if f(a)=f(a′)⇒a=a′, surjective if every b∈B equals some f(a), and bijective if both.

Sequence over S: a function from a subset of ℕ (usually {0,1,2,…} or {1,2,3,…}) to S; written ⟨an⟩ with an=f(n). A sequence is finite or infinite according to its domain.

The four relation properties, with examples

PropertyFormal statement, example that holds, example that fails
Reflexive∀a∈A, (a,a)∈R. Holds: ≤ on ℤ. Fails: < on ℤ, since 2<2 is false.
Symmetric(a,b)∈R ⇒ (b,a)∈R. Holds: = on any set. Fails: ≤ on ℤ, since 2≤3 but 3≰2.
Antisymmetric(a,b)∈R and (b,a)∈R ⇒ a=b. Holds: ⊆ on 2^S. Fails: "|a−b|≤1" on ℤ, since 1~2 and 2~1 but 1≠2.
Transitive(a,b)∈R and (b,c)∈R ⇒ (a,c)∈R. Holds: ≤ on ℤ. Fails: "|a−b|=1" on ℤ, since 1~2 and 2~3 but 1≁3.

Notice that symmetric and antisymmetric are not opposites: the equality relation is both, the relation ≤ is antisymmetric but not symmetric, and "|a−b|≤1" is symmetric but not antisymmetric.

Composition of relations

If R1⊆A×B and R2⊆B×C, then R1∘R2 = {(x,z)∈A×C : ∃y∈B with (x,y)∈R1 and (y,z)∈R2}. In words: travel from A to B using R1, then from B to C using R2.

Example. A={1,2}, B={a,b}, C={x,y}, R1={(1,a),(2,b)}, R2={(a,x),(b,x)}. Then R1∘R2={(1,x),(2,x)}; nothing lands in y because no pair in R2 ends in y.

Notation warning (from the slides). The slide displays R1∘R2 with the definition above, then remarks "note the notation R2∘R1". Textbooks differ on the order. In this guide R1∘R2 always means "first R1, then R2", exactly as displayed on the slide; check your instructor's convention before the exam.

Russell's paradox

Let A = {S : S is a set and S∉S}. Is A∈A?

  • If A∈A, then A satisfies the defining property, so A∉A: a contradiction.
  • If A∉A, then A satisfies the defining property, so A∈A: a contradiction.

Both cases are impossible, so unrestricted set-builder notation is inconsistent. This motivated axiomatic set theory, which restricts how sets may be formed. In this course every set is built inside a fixed universal set, so the paradox never arises.

Partial and total orders

Partial order: a relation that is reflexive, antisymmetric and transitive. A set together with a partial order is a poset.

Total order: a partial order in which every two elements are comparable: for all a,b, (a,b)∈R or (b,a)∈R. A totally ordered set is also called a chain.

Examples. (ℤ,≤) is a total order. (2^S,⊆) is a partial order but not total once S has two elements: {1} and {2} are incomparable. Divisibility on ℤ+ is a partial order but not total: 2 and 3 are incomparable.

5. Theorems and complete proofs

Every proof below is written as numbered steps. "By definition" means the step is exactly the definition; the other justifications are named (reflexivity, symmetry, transitivity, the division algorithm, and so on).

Theorem 1: congruence modulo n is an equivalence relation

Let n∈ℤ+ and define, for a,b∈ℤ, a~b ⟺ n | (a−b). Then ~ is an equivalence relation on ℤ. Exam likely.

  1. Reflexive. For any a∈ℤ, a−a=0 and n|0 because 0=n·0. Hence a~a.
  2. Symmetric. Suppose a~b, so a−b=nk for some k∈ℤ. Then b−a=−(a−b)=n(−k), and −k∈ℤ, so n|(b−a), i.e. b~a.
  3. Transitive. Suppose a~b and b~c, so a−b=nk and b−c=nℓ. Adding, a−c=(a−b)+(b−c)=n(k+ℓ), and k+ℓ∈ℤ, so a~c.
  4. Conclusion. All three properties hold, so ~ is an equivalence relation. ∎

Why n>0 matters: "0 | (a−b)" would mean a−b=0·k=0, which fails for a≠b, and divisibility by 0 is undefined. The theorem is stated for n≥1.

Theorem 2: the classes of ≡ (mod n) are exactly [0], [1], …, [n−1]

For n≥1, the distinct equivalence classes of congruence modulo n are [0], [1], …, [n−1]; hence ℤ/nℤ has exactly n elements. Exam likely.

  1. Division algorithm (standard). For every a∈ℤ there are unique integers q, r with a=qn+r and 0≤r<n.
  2. Every class meets {0,1,…,n−1}. From step 1, a−r=qn, so n|(a−r), i.e. a~r. If x∈[a] then a~x; since r~a by symmetry, transitivity gives r~x, so x∈[r]. Exchanging a and r gives the reverse inclusion, so [a]=[r].
  3. The classes [0],…,[n−1] are distinct. If 0≤r<s<n, then 0<s−r<n, and no positive multiple of n is smaller than n; so n∤(s−r), i.e. r≢s.
  4. Conclusion. The n classes [0],…,[n−1] are pairwise distinct and every class equals one of them, so ℤ/nℤ = {[0],[1],…,[n−1]} has exactly n elements. ∎

Theorem 3: every element lies in its own class

If R is an equivalence relation on A and a∈A, then a∈[a], so [a] is nonempty and [a]⊆A.

  1. Membership. By reflexivity (a,a)∈R, and the definition of [a] then gives a∈[a].
  2. Nonempty. A set containing the element a is not empty.
  3. Subset. Every element of [a] is by definition an element of A, so [a]⊆A. ∎

Theorem 4: any member of a class represents it

If R is an equivalence relation on A, then for a,b∈A: a~b ⟺ [a]=[b].

  1. (⇒) Assume a~b. Let x∈[a], so a~x. Since b~a (symmetry) and a~x, transitivity gives b~x, so x∈[b]. Hence [a]⊆[b].
  2. (⇒) reverse inclusion. The same argument with a and b exchanged (using a~b again) gives [b]⊆[a].
  3. (⇒) conclusion. Two inclusions give [a]=[b].
  4. (⇐) Assume [a]=[b]. By Theorem 3, b∈[b]=[a], and the definition of [a] says exactly a~b. ∎

Theorem 5: two classes are disjoint or equal

If R is an equivalence relation on A, then for any a,b∈A, either [a]∩[b]=∅ or [a]=[b]. Exam likely.

  1. Case 1: the intersection is empty. Then there is nothing to prove.
  2. Case 2: the intersection is nonempty. Choose c∈[a]∩[b]. Then a~c and b~c.
  3. Derive a~b. By symmetry c~b; with a~c, transitivity gives a~b.
  4. Apply Theorem 4. Since a~b, [a]=[b].
  5. Conclusion. Either the intersection is empty or the classes are equal; there is no third possibility. ∎

See it. The picture shows the only interesting case: one common element c is enough to force the two classes to be identical.

Theorem 6: the classes cover A

If R is an equivalence relation on A, then ⋃a∈A[a] = A. Exam likely.

  1. (⊆) Each [a]⊆A by Theorem 3, so a union of subsets of A is again a subset of A.
  2. (⊇) Let x∈A. By Theorem 3, x∈[x], and [x] is one of the sets being unioned, so x belongs to the union.
  3. Conclusion. Both inclusions hold, hence equality. ∎

Theorem 7: equivalence relations on A are exactly the partitions of A

Let R be an equivalence relation on A. Then its equivalence classes form a partition of A. Conversely, every partition of A arises from exactly one equivalence relation, namely "a~b iff a and b lie in the same block". Exam likely.

Direction 1: relation → partition.

  1. Nonempty blocks. Each class [a] contains a by Theorem 3, so no block is empty.
  2. Pairwise disjoint. Any two classes are disjoint or equal by Theorem 5; "disjoint or equal" is exactly the condition that distinct blocks do not overlap.
  3. Union is A. The classes cover A by Theorem 6.
  4. Conclusion. A collection of nonempty, pairwise disjoint subsets with union A is a partition, by definition.

Direction 2: partition → relation. Let {Bi : i∈I} be a partition of A and define a~b ⟺ a,b lie in the same block.

  1. Well defined. Every a∈A lies in at least one block because the union is A, and in at most one because distinct blocks are disjoint; so "the block containing a" is unique.
  2. Reflexive. a lies in the same block as itself, so a~a.
  3. Symmetric. "Same block" is unchanged when a and b are exchanged, so a~b ⇒ b~a.
  4. Transitive. If a~b and b~c, then b lies in the block of a and in the block of c. By uniqueness of the block containing b, those blocks coincide, so a and c are in the same block, i.e. a~c.
  5. Classes are the blocks. For a∈Bi, [a] = {b : b in the same block as a} = Bi. Conversely each block Bi is nonempty, so it equals [a] for any of its elements a.
  6. The two constructions are inverse. Relation → partition → relation returns the original R: by Theorem 4, a~b holds exactly when a and b have the same class. Partition → relation → partition returns the original blocks by step 5. Hence the correspondence is a bijection. ∎

Theorem 8: counting equivalence relations with Stirling and Bell numbers

For a set A with |A|=n≥1, the number of equivalence relations on A with exactly k classes is the Stirling number of the second kind S(n,k), and the total number of equivalence relations is the Bell number Bn = S(n,1)+S(n,2)+⋯+S(n,n). Not in slides — standard result (the slides state the correspondence, not this count).

  1. Bijection. By Theorem 7, the map R ↦ (its set of classes) is a bijection from equivalence relations on A to partitions of A, and it preserves the number of classes.
  2. Definition of S(n,k). S(n,k) is defined as the number of partitions of an n-element set into exactly k nonempty blocks (page 03). Applying the bijection of step 1, this equals the number of equivalence relations with k classes.
  3. Total. Every equivalence relation has some number of classes between 1 and n, and these cases are disjoint, so the total is the sum S(n,1)+⋯+S(n,n), which is the definition of Bn.
  4. Corollary S(n,2)=2n−1−1. A 2-block partition is determined by the block containing a fixed element a1: that block can be any subset containing a1 except the whole set A (otherwise the second block would be empty). There are 2n−1 subsets containing a1, so S(n,2)=2n−1−1. ∎

Theorem 9: the Stirling recurrence

For n≥1 and 1≤k≤n: S(n,k) = k·S(n−1,k) + S(n−1,k−1), with S(0,0)=1 and S(n,k)=0 when k>n or k=0<n.

  1. Fix an element. Let |A|=n and fix x∈A. Every partition of A into k blocks falls into exactly one of two cases.
  2. Case 1: {x} is a block. The remaining n−1 elements are partitioned into the other k−1 blocks, which can be done in S(n−1,k−1) ways.
  3. Case 2: x shares its block. Delete x from its block. The remaining n−1 elements now form a partition into k blocks, which can be chosen in S(n−1,k) ways. To rebuild the original partition, insert x into any one of those k blocks: k choices. This gives k·S(n−1,k) partitions.
  4. No double counting. Case 1 partitions have {x} as a block; case 2 partitions do not. The two families are disjoint, and every partition is in one of them.
  5. Add. Therefore S(n,k) = k·S(n−1,k) + S(n−1,k−1). The boundary values follow from the definition: the empty set has one partition into zero blocks, and a set cannot be split into more nonempty blocks than it has elements. ∎

6. Worked examples

The examples run from routine property checks to counting; each one shows the working, not only the answer.

Example 1 (easy): divisibility on ℤ+

On ℤ+ define a~b ⟺ a|b. Test the three equivalence properties.

  • Reflexive: a=a·1, so a|a. Holds.
  • Transitive: if a|b and b|c, write b=am and c=bn; then c=a(mn), so a|c. Holds.
  • Symmetric: 2|4 but 4∤2. Fails.

Hence divisibility is not an equivalence relation on ℤ+; it is a partial order (it is also antisymmetric: if a|b and b|a with a,b>0 then a=b). The single failing property is symmetry, which is exactly what an exam question asks for.

Example 2 (easy): the four classes modulo 4

For n=4, Theorem 2 says the classes are [0], [1], [2], [3]. Concretely,

  • [0] = {…,−8,−4,0,4,8,…} (multiples of 4),
  • [1] = {…,−7,−3,1,5,9,…} (remainder 1),
  • [2] = {…,−6,−2,2,6,10,…} (remainder 2),
  • [3] = {…,−5,−1,3,7,11,…} (remainder 3).

Every integer has exactly one remainder in {0,1,2,3} on division by 4, so these four sets are disjoint and cover ℤ. For instance −7=4·(−2)+1, so −7∈[1]; and 7=4·1+3, so 7∈[3]. This is the partition promised by Theorem 7, and |ℤ/4ℤ|=4.

Example 3 (easy–medium): same parity on {1,2,3,4}

Let A={1,2,3,4} and a~b ⟺ a−b is even. Then R consists of the pairs

(1,1), (1,3), (2,2), (2,4), (3,1), (3,3), (4,2), (4,4).

  • Reflexive: (a,a) is in the list for all four elements, since a−a=0 is even.
  • Symmetric: whenever (a,b) is listed, so is (b,a), because b−a=−(a−b).
  • Transitive: even differences add: if a−b and b−c are even, so is a−c.

The classes are [1]={1,3} and [2]={2,4}; together they partition {1,2,3,4}. The digraph in section 3 is exactly this relation.

Example 4 (medium): all equivalence relations on a 3-element set

By Theorem 8, the count is B3=S(3,1)+S(3,2)+S(3,3)=1+3+1=5. Listing the partitions of {α,β,γ} shows where the numbers come from:

  1. one block: {α,β,γ} (the universal relation);
  2. two blocks: {α,β}|{γ}, {α,γ}|{β}, {β,γ}|{α} (3 of them);
  3. three blocks: {α}|{β}|{γ} (the equality relation).

So 1+3+1=5. The relation for the second partition is the pairs inside each block, i.e. (α,α),(α,β),(β,α),(β,β),(γ,γ).

Example 5 (medium): exactly 2 classes on 6 elements

By Theorem 8, S(6,2)=26−1−1=25−1=31.

Direct count. A 2-block partition is fixed by the block containing 1. That block must contain 1 and must not be all of {1,…,6}, so it is a nonempty proper subset containing 1. There are 25=32 subsets containing 1 (each of 2,…,6 is in or out), and exactly one of them is the whole set, so 32−1=31.

Example 6 (medium–hard): exactly 3 classes on 5 elements, two ways

Via the recurrence (Theorem 9). S(5,3)=3·S(4,3)+S(4,2)=3·6+7=18+7=25.

Via block sizes (independent check). The block-size patterns of 5 into 3 positive parts are 3+1+1 and 2+2+1.

  • 3+1+1: choose the 3-element block, C(5,3)=10; the other two elements are forced to be singletons. Gives 10.
  • 2+2+1: choose the singleton, 5 ways; split the remaining 4 elements into two unordered pairs, which can be done in 3 ways: {12|34}, {13|24}, {14|23}. Gives 5·3=15.

Total 10+15=25, matching the recurrence. This example is practice question Q11.

Example 7 (hard): reflexive + symmetric is not enough

How many relations on A={1,2,3} are reflexive and symmetric, and how many of those are equivalence relations?

Count reflexive + symmetric. Reflexivity forces the three diagonal pairs (1,1),(2,2),(3,3) into R. Symmetry forces the three off-diagonal pairs {1,2}, {1,3}, {2,3} to be either both present or both absent. That is 3 independent binary choices, so 23=8 relations.

Which are transitive? View the chosen off-diagonal pairs as edges of a graph on 3 vertices. Transitivity says: if a~b and b~c then a~c, i.e. every connected component must be a complete graph. The possibilities are:

  • no edges: three singleton blocks — 1 relation;
  • exactly one edge: one pair plus an isolated vertex — 3 relations;
  • all three edges: one block — 1 relation.

That is 1+3+1=5 equivalence relations. The other 3 of the 8 (the two-edge paths, e.g. {12},{23} without {13}) are reflexive and symmetric but not transitive. So 8−5=3 relations fail exactly at transitivity.

Example 8 (hard): counting functions between finite sets

Let |A|=3 and |B|=5. Count functions f:A→B.

  • All functions: each of the 3 inputs chooses one of 5 outputs independently, so 53=125.
  • Injective: the first input has 5 choices, the second 4 (a different output), the third 3, so 5·4·3=60.
  • Surjective: a surjection needs at least one input per output, so it needs |A|≥|B|. Here 3<5, so 0.
  • Bijective: impossible for the same reason, so 0.

Sanity check: 60 injective functions are a subset of the 125 total functions, and 60≤125. The count 5·4·3 is also written P(5,3)=5!/(5−3)!.

9. Common mistakes and exam traps

Each trap is shown as the wrong statement next to the corrected one, with a concrete example you can reproduce in the exam.

  • Forgetting reflexivity. Wrong: "R={(1,1),(2,2)} on {1,2,3} is symmetric and transitive, so it is an equivalence relation." Right: (3,3)∉R, so R is not reflexive and therefore not an equivalence relation; its "classes" would not cover 3.
  • Confusing symmetric with antisymmetric. Wrong: "R={(1,2),(2,1)} is antisymmetric because the two pairs are reverses of each other." Right: antisymmetry requires (a,b) and (b,a) to force a=b; here 1≠2, so R is symmetric but not antisymmetric. The relation ≤ is antisymmetric but not symmetric.
  • Allowing empty blocks. Wrong: "{{1,2}, ∅, {3}} is a partition of {1,2,3}." Right: a partition's blocks are nonempty by definition, and every class [a] contains a (Theorem 3), so ∅ can never be a class.
  • Counting all relations instead of equivalence relations. Wrong: "There are 29=512 equivalence relations on a 3-element set." Right: 512 is the number of all relations on a 3-element set (23·3); only B3=5 of them are equivalence relations (Example 4).
  • Thinking a class is named by its smallest element. Wrong: "In ℤ/4ℤ, [1]={1} because 1 is the representative." Right: [1]={…,−7,−3,1,5,9,…}; every member represents the class, so [1]=[5]=[−3].
  • Mixing up partitions of a set and partitions of an integer. Wrong: "The partitions of {1,2,3} are 3, 2+1, 1+1+1." Right: those are the integer partitions of 3 (page 07). The set partitions are {123}, {12}{3}, {13}{2}, {23}{1}, {1}{2}{3}: five of them, matching B3=5.
  • Calling every relation a function. Wrong: "R={(1,1),(1,2)} is a function from {1} to {1,2}." Right: the input 1 has two images, so R is a relation but not a function; a function needs exactly one image per input.
  • Checking transitivity only on the pairs you happen to list. Wrong: "R={(1,2),(2,3)} is transitive because 1~2 and 2~3 look fine." Right: transitivity demands (1,3)∈R; it is missing, so R is not transitive. Always chase every head-to-tail chain.

10. Practice questions (assigned to this page)

Q1. How many equivalence relations on {1,2,3,4,5,6} have exactly 2 equivalence classes?

Solution. By Theorem 8 the answer is S(6,2)=26−1−1=31.

Where the formula comes from. A 2-block partition is determined by the block B containing 1: once B is chosen, the other block is its complement. The block B must contain 1 and must be a proper subset (otherwise the complement is empty). Each of 2,3,4,5,6 independently is either in B or not, giving 25=32 subsets containing 1; the one bad choice is B={1,…,6}. Hence 32−1=31.

Consistency check. The recurrence gives S(6,2)=2·S(5,2)+S(5,1)=2·15+1=31, using S(5,2)=15 and S(5,1)=1.

Q2. Define a~b on ℤ by a~b ⟺ 2 | (a+b). Is ~ an equivalence relation?

Solution: yes. Check the three properties with algebra, not just examples.

  1. Reflexive: a+a=2a, and 2|2a. So a~a.
  2. Symmetric: a+b=b+a, so 2|(a+b) exactly when 2|(b+a).
  3. Transitive: suppose 2|(a+b) and 2|(b+c). Then their sum 2|a+2b+c is even. Subtracting the even number 2b leaves a+c even, so 2|(a+c). Hence a~c.

Classes. a+b is even exactly when a and b have the same parity, so the two classes are the even integers and the odd integers. They partition ℤ, as Theorem 7 predicts.

Q3. How many equivalence relations are there on the set {α, β, γ}?

Solution. B3=S(3,1)+S(3,2)+S(3,3)=1+3+1=5. Listing them makes the count transparent:

  1. {α,β,γ} — one block, the universal relation;
  2. {α,β}|{γ};
  3. {α,γ}|{β};
  4. {β,γ}|{α};
  5. {α}|{β}|{γ} — three blocks, the equality relation.

The three 2-block cases come from choosing which pair is together (C(3,2)=3), and the two 1-block/3-block cases are forced.

Q11. How many equivalence relations with exactly 3 classes are there on a 5-element set?

Solution. S(5,3)=25. Two independent derivations:

(a) Recurrence. S(5,3)=3·S(4,3)+S(4,2)=3·6+7=18+7=25, using the row S(4,1..4)=1,7,6,1.

(b) Block sizes. A partition of 5 into 3 nonempty blocks has shape 3+1+1 or 2+2+1.

  • 3+1+1: choose the 3-element block in C(5,3)=10 ways; the remaining two elements are singleton blocks. 10 partitions.
  • 2+2+1: choose the singleton in 5 ways; split the remaining 4 elements into two unordered pairs in 3 ways ({12|34}, {13|24}, {14|23}). 5·3=15 partitions.

Total 10+15=25, matching (a).

Q25. How many equivalence relations are possible on the set {1, 0.5, 1/3, √2}?

Solution. First check that the four objects are distinct: 1≠0.5, 1≠1/3, 0.5=1/2≠1/3, and √2 is irrational while the other three are rational, so √2 differs from all of them. Hence the set has exactly 4 elements.

By Theorem 8 the number of equivalence relations depends only on the cardinality, so it is B4=S(4,1)+S(4,2)+S(4,3)+S(4,4)=1+7+6+1=15.

Interpretation of the four terms. 1 relation with one class (everything equivalent), 7 with two classes, 6 with three classes, 1 with four classes (equality). Note that the values of the elements are irrelevant; only the fact that there are four of them matters.

11. Extra self-test questions

Eight questions with full answers. Cover the answer, then check each step.

1. How many equivalence relations are there on a 4-element set?

Answer: 15. By Theorem 8, B4=S(4,1)+S(4,2)+S(4,3)+S(4,4)=1+7+6+1=15. The terms count relations with 1, 2, 3 and 4 classes. Equivalently, the partitions of a 4-element set by block sizes are: 4 (1 way), 3+1 (4 ways), 2+2 (3 ways), 2+1+1 (6 ways), 1+1+1+1 (1 way); total 1+4+3+6+1=15.

2. How many equivalence relations on a 4-element set have exactly 2 classes?

Answer: 7. By Theorem 8, S(4,2)=23−1=7. Concretely, the block containing 1 can be {1}, {1,2}, {1,3}, {1,4}, {1,2,3}, {1,2,4} or {1,3,4}; the seventh subset containing 1 is the whole set, which would leave the second block empty and is excluded.

3. Is "a divides b" an equivalence relation on ℤ+?

Answer: no. Reflexive: a|a (take quotient 1). Transitive: a|b and b|c give b=am, c=bn, hence c=a(mn). But symmetry fails: 2|4 while 4∤2. So it is a partial order, not an equivalence relation.

4. How many partitions of {1,2,3,4} into exactly 2 blocks are there?

Answer: 7. List by the block containing 1: {1}|{2,3,4}, {1,2}|{3,4}, {1,3}|{2,4}, {1,4}|{2,3}, {1,2,3}|{4}, {1,2,4}|{3}, {1,3,4}|{2}. That is 7, matching S(4,2)=23−1.

5. Is congruence modulo 5 an equivalence relation on ℤ?

Answer: yes. a≡a because 5|0; if 5|(a−b) then 5|(b−a); and if 5|(a−b) and 5|(b−c) then 5|(a−c) by adding. The classes are [0],[1],[2],[3],[4], so ℤ/5ℤ has 5 elements. For example 17≡2 (mod 5) because 17−2=15=5·3.

6. Is R = {(1,1), (2,2), (3,3), (1,2), (2,1)} an equivalence relation on {1,2,3}?

Answer: yes. Reflexive: all three loops are present. Symmetric: the only off-diagonal pairs are (1,2) and (2,1), a reverse pair. Transitive: the only chains to check are (1,2) followed by (2,1), which needs (1,1) — present; and (2,1) followed by (1,2), which needs (2,2) — present; chains using loops need nothing new. The classes are [1]={1,2} and [3]={3}.

7. Of the 16 relations on {1,2}, how many are equivalence relations?

Answer: 2. A relation on a 2-element set is a subset of the 4 ordered pairs, so there are 24=16 relations. An equivalence relation is a partition: either one block {1,2} (the universal relation {(1,1),(1,2),(2,1),(2,2)}) or two blocks {1}|{2} (the equality relation {(1,1),(2,2)}). That is B2=2. Every other relation fails reflexivity, symmetry or transitivity; for instance {(1,1),(1,2)} fails symmetry and {(1,2),(2,1)} fails reflexivity.

8. If |A|=3 and |B|=5, how many functions A→B are there? How many are injective? Surjective?

Answer: 125 total, 60 injective, 0 surjective. Each of the 3 inputs independently picks one of 5 outputs: 53=125. An injection uses distinct outputs, so 5·4·3=60. A surjection would need at least 5 inputs (one per output), and 3<5, so none exist; in particular no bijection exists either.

12. Cheat sheet

Sets and functions

  • A⊆B ⟺ every element of A is in B; A=B ⟺ A⊆B and B⊆A.
  • Power set 2^A = {S : S⊆A}; |2^A|=2|A|.
  • A×B = {(a,b) : a∈A, b∈B}; |A×B|=|A|·|B|.
  • Function f:A→B: every input has exactly one output. Injective: f(a)=f(a′)⇒a=a′. Surjective: every b∈B is hit. Bijective: both.
  • For |A|=n, |B|=m: functions mn; injections m(m−1)⋯(m−n+1) when n≤m; bijections n! when n=m; surjections 0 when n<m.
  • Sequence over S: a function from a subset of ℕ to S, written ⟨an⟩.

Relations

  • Binary relation R⊆A×B; relation on A when A=B. n-ary relation: subset of A1×⋯×An.
  • Reflexive: ∀a, (a,a)∈R. Symmetric: (a,b)∈R⇒(b,a)∈R. Antisymmetric: (a,b),(b,a)∈R⇒a=b. Transitive: (a,b),(b,c)∈R⇒(a,c)∈R.
  • Composition: R1∘R2={(x,z) : ∃y, (x,y)∈R1 and (y,z)∈R2}; order convention varies.
  • Partial order: reflexive + antisymmetric + transitive (poset). Total order: every pair comparable (chain).

Equivalence relations

  • Equivalence relation = reflexive + symmetric + transitive.
  • Class [a]={b : (a,b)∈R}; a∈[a]; a~b ⟺ [a]=[b].
  • Classes are nonempty, pairwise disjoint or equal, and their union is A.
  • Equivalence relations on A ↔ partitions of A (classes ↔ blocks).
  • Congruence: a≡b (mod n) ⟺ n|(a−b); an equivalence relation for n≥1.
  • ℤ/nℤ={[0],[1],…,[n−1]}, exactly n classes.

Counting equivalence relations

  • S(n,k) = number of partitions of an n-set into exactly k blocks = number of equivalence relations with k classes.
  • Bn=S(n,1)+⋯+S(n,n) = total number of equivalence relations on an n-set.
  • S(n,k)=k·S(n−1,k)+S(n−1,k−1); S(n,1)=1; S(n,n)=1; S(n,2)=2n−1−1.
  • First values: B1=1, B2=2, B3=5, B4=15, B5=52, B6=203.

Stirling rows (row n lists S(n,1), …, S(n,n)):

  • n=1: 1
  • n=2: 1, 1
  • n=3: 1, 3, 1
  • n=4: 1, 7, 6, 1
  • n=5: 1, 15, 25, 10, 1
  • n=6: 1, 31, 90, 65, 15, 1

Exam checklist

  • To prove "equivalence relation": check reflexivity, symmetry, transitivity, in that order, with algebra not examples.
  • To prove "not an equivalence relation": one concrete counterexample to one property is enough.
  • To count with k classes: use S(n,k); to count all: use Bn.
  • To show two classes are equal: exhibit one common element, then quote Theorem 5.
