06 Generating Functions

1. Why this topic matters

Generating functions turn recurrence and counting problems into algebra. Instead of manipulating sequences term by term, you manipulate a single power series and read off coefficients. Fibonacci, redundant combinations, and partitions all become simple rational functions. The skill is setting up the series correctly and extracting the coefficient.

2. Prerequisites

Sequences and recurrences from page 01 and page 05; basic counting from page 02.

3. Intuition

A generating function is a clothesline: hang the sequence terms as coefficients of powers of x. Multiplying series corresponds to combining independent choices, so counting problems become polynomial multiplication. The first picture shows Fibonacci terms hanging on the line; the second shows why multiplying by x shifts every coefficient one place to the right.

4. Definitions

Ordinary generating function: for sequence a_0,a_1,..., G(x)=Σ_{n≥0} a_n x^n.

Coefficient extraction: [x^n]G(x)=a_n.

Geometric series: 1/(1-x)=1+x+x^2+... .

Derivative/integral and shifts: multiplying by x shifts indices; these are the main algebraic tools.

5. Theorems and complete proofs

Every identity below is proved by expanding a product of power series and reading off a coefficient.

Theorem: product of generating functions (convolution)

If G(x)=Σn≥0anxn and H(x)=Σn≥0bnxn, then G(x)H(x) = Σn≥0 cnxn with cn = Σi=0n aibn−i.

  1. Multiply term by term. G(x)H(x) = Σi,j≥0 aibjxi+j.
  2. Collect like powers. The coefficient of xn receives exactly the pairs with i+j=n, i.e. j=n−i with 0≤i≤n.
  3. Write the coefficient. Hence cn = Σi=0naibn−i; the sum is finite, so no convergence issue arises for a formal power series. ∎

Theorem: Fibonacci generating function

If F0=0, F1=1, Fn=Fn−1+Fn−2, then G(x)=x/(1−x−x2). Exam likely.

  1. Write the series. G(x) = F0 + F1x + Σn≥2Fnxn = x + Σn≥2Fnxn.
  2. Use the recurrence. Replace Fn by Fn−1+Fn−2, so the tail becomes Σn≥2Fn−1xn + Σn≥2Fn−2xn.
  3. Factor out powers of x. The first sum is xΣn≥2Fn−1xn−1 = x(G−F0) = xG, and the second is x2Σn≥2Fn−2xn−2 = x2G.
  4. Solve. G = x + xG + x2G, so G(1−x−x2) = x and G(x)=x/(1−x−x2). ∎

Theorem: redundant combinations via generating functions

The number of multisets of size r from n types is C(n+r−1,r), and the generating function is 1/(1−x)n.

  1. Encode a multiset by counts. If type i is chosen yi times, the multiset of size r satisfies y1+…+yn=r with every yi≥0.
  2. One type contributes a geometric series. The possible counts 0,1,2,… give the factor 1+x+x2+… = 1/(1−x).
  3. Multiply the independent types. By the convolution theorem, the product (1/(1−x))n has coefficient of xr equal to the number of count-tuples summing to r.
  4. Extract the coefficient. By the binomial series below, [xr](1−x)−n = C(n+r−1,r). ∎

Theorem: compositions with order counting

The number of compositions of n into exactly r positive parts is C(n−1,r−1), with generating function (x/(1−x))r.

  1. Model one part. A positive part can be 1, 2, 3, …, contributing x+x2+… = x/(1−x).
  2. Multiply r ordered parts. The product is xr/(1−x)r; order is already built in because the factors are distinguished.
  3. Shift the coefficient. [xn] xr/(1−x)r = [xn−r](1−x)−r = C(r+(n−r)−1,n−r) = C(n−1,r−1), using the symmetry of binomial coefficients. ∎

Theorem: binomial series

(1−x)−r = Σm≥0 C(r+m−1,m) xm.

  1. Write the reciprocal as a power. (1−x)−r = (1+x+x2+…)r.
  2. Expand the product. By the convolution theorem, the coefficient of xm is the number of r-tuples of nonnegative integers whose entries sum to m.
  3. Count those tuples. Stars and bars gives C(m+r−1,r−1) = C(m+r−1,m).
  4. Equivalent form. The same coefficient is (−1)mC(−r,m), the generalized binomial theorem with exponent −r. ∎

6. Worked examples

Example 1 (easy): the geometric series

Since 1/(1−x) = 1+x+x2+…, every coefficient is 1: [xn]1/(1−x) = 1. Replacing x by 2x gives 1/(1−2x) = Σ2nxn, so [x2]1/(1−2x) = 22 = 4.

Example 2 (easy): a negative power

Use the binomial series with r=3: (1−x)−3 = Σm≥0 C(3+m−1,m)xm. Hence [x4](1−x)−3 = C(3+4−1,4) = C(6,4) = 15.

Example 3 (easy): compositions

Compositions of 7 into 4 positive parts have generating function (x/(1−x))4, so the count is [x7]x4(1−x)−4 = [x3](1−x)−4 = C(4+3−1,3) = C(6,3) = 20. Direct check: the patterns 4+1+1+1 give 4 orders, 3+2+1+1 give 12, and 2+2+2+1 give 4, total 20. ✔

Example 4 (medium): Fibonacci coefficients

From G(x)=x/(1−x−x2) we have [xn]G = Fn. In particular [x5]G = F5 = 5, matching the sequence 0, 1, 1, 2, 3, 5 hung on the clothesline in section 3.

Example 5 (medium): a linear recurrence from its generating function

For 1, 5, 19, 65, … with an = 5an−1−6an−2, a0=1, a1=5, multiply by xn and sum: G−a0−a1x = 5x(G−a0)−6x2G, so G = (a0+(a1−5a0)x)/(1−5x+6x2) = 1/(1−5x+6x2). Partial fractions: 1/((1−2x)(1−3x)) = −2/(1−2x) + 3/(1−3x), so an = −2·2n+3·3n = 3n+1−2n+1. Check n=2: 27−8=19. ✔

Example 6 (medium): redundant combinations

Multisets of 5 fruits from 3 types have generating function (1−x)−3, so the count is [x5](1−x)−3 = C(3+5−1,5) = C(7,5) = 21.

Example 7 (hard): a constrained selection

Choose 4 fruits with pomegranate and banana at most 1 each, mango at most 2, oranges unrestricted. The generating function is (1+x)(1+x)(1+x+x2)(1+x+x2+x3+x4+…). Multiply the first two: (1+x)2 = 1+2x+x2. Multiply by (1+x+x2): coefficients 1, 3, 4, 3, 1 for degrees 0–4. Convolving with the all-ones orange series, the coefficient of x4 is 1+3+4+3+1 = 12. Direct enumeration of the four bounded counts gives the same 12.

9. Common mistakes and exam traps

  1. Forgetting the initial terms when shifting. For Fibonacci, wrong: subtract the three series and conclude G−xG−x2G=0, so G=0. Right: the surviving term is F0+(F1−F0)x=x, giving G=x/(1−x−x2).
  2. Misreading a shift. Wrong: [xn](xG)=an. Right: [xn](xG)=an−1, and [x0](xG)=0.
  3. Wrong bottom number in a coefficient. Wrong: [x4](1−x)−3=C(6,3)=20. Right: C(3+4−1,4)=C(6,4)=15; the bottom is the exponent 4, or equivalently 3.
  4. Not factoring before partial fractions. Wrong: split 1/(1−5x+6x2) as if the denominator were already linear. Right: factor as (1−2x)(1−3x), giving −2/(1−2x)+3/(1−3x) and an=3n+1−2n+1.
  5. Forgetting that parts must be positive. Wrong: (1/(1−x))4 for 7 into 4 parts gives C(10,3)=120. Right: each part is positive, so use (x/(1−x))4 and get C(6,3)=20.
  6. Off-by-one in Fibonacci extraction. Wrong: [x5]x/(1−x−x2)=F4=3. Right: it is F5=5, because the series starts x+x2+2x3+3x4+5x5+…
  7. Using exponential rather than ordinary generating functions. Wrong: divide coefficients by n! and expect [x5](1−x)−3/5! to count multisets. Right: this course uses ordinary generating functions; [x5](1−x)−3=21 directly.

10. Practice questions (assigned to this page)

Q13. Find the generating function for partitions of n into exactly r parts where order counts, and give the compact form of A(n,r).

Step 1 — model one part. "Order counts" means a composition: an ordered list of r positive integers summing to n. A single part may be 1, 2, 3, …, so its generating function is x+x2+x3+… = x/(1−x).

Step 2 — multiply the ordered parts. The r positions are distinguishable, so by the convolution theorem the generating function is

G(x) = (x/(1−x))r = xr (1−x)−r.

Step 3 — extract the coefficient. A(n,r) = [xn]G = [xn−r](1−x)−r = C(r+(n−r)−1,n−r) = C(n−1,n−r) = C(n−1,r−1).

Step 4 — verify a case. For n=7, r=4, A(7,4)=C(6,3)=20, and the brute-force lists 4+1+1+1 (4 orders), 3+2+1+1 (12 orders) and 2+2+2+1 (4 orders) give 4+12+4=20. ✔

11. Extra self-test questions

1. Coefficient of x4 in (1−x)−3?

By the binomial series, [x4](1−x)−3 = C(3+4−1,4) = C(6,4) = 15.

2. Find the Fibonacci generating function.

With F0=0, F1=1, the subtraction G−xG−x2G leaves F0+(F1−F0)x=x, so G(x)=x/(1−x−x2).

3. Compositions of 10 into 3 positive parts?

Generating function (x/(1−x))3, so the count is [x7](1−x)−3 = C(3+7−1,7) = C(9,7) = C(9,2) = 36.

4. Redundant combinations of 5 from 3 types?

Generating function (1−x)−3, so [x5](1−x)−3 = C(3+5−1,5) = C(7,5) = 21.

5. Coefficient of x2 in 1/(1−2x)?

1/(1−2x) = Σ2nxn, so the coefficient is 22 = 4.

6. Coefficient of x5 in (1−x)−4?

[x5](1−x)−4 = C(4+5−1,5) = C(8,5) = 56.

7. Coefficient of x3 in (1+x)6?

By the binomial theorem it is C(6,3) = (6·5·4)/(3·2·1) = 20.

8. Coefficient of x6 in x2/(1−x)3?

Shift: [x6]x2(1−x)−3 = [x4](1−x)−3 = C(3+4−1,4) = C(6,4) = 15.

12. Cheat sheet

Definitions

  • Ordinary generating function: G(x) = Σn≥0anxn.
  • Coefficient extraction: [xn]G = an.
  • Geometric series: 1/(1−x) = 1+x+x2+…
  • Convolution: [xn](GH) = Σi=0naibn−i.
  • Shift: [xn](xG) = an−1.

Formulas

  • (1−x)−r = Σm≥0 C(r+m−1,m) xm.
  • Fibonacci: G(x) = x/(1−x−x2).
  • Multisets of size r from n types: 1/(1−x)n, coefficient C(n+r−1,r).
  • Compositions of n into r positive ordered parts: (x/(1−x))r, coefficient C(n−1,r−1).
  • A linear recurrence gives a rational G: G = (a0+(a1−c1a0)x)/(1−c1x−c2x2).
  • Factor the denominator, use partial fractions, then expand 1/(1−αx) = Σαnxn.
  • Constrained choices: one factor per item, truncated at its upper bound.

Exam checklist

  1. Write the generating function from the allowed values of each item.
  2. Keep initial terms when multiplying by x or x2.
  3. Use (1−x)−r and its coefficient formula.
  4. For a recurrence, factor the denominator before partial fractions.
  5. State the final answer as a coefficient and, where possible, check it by brute force.
