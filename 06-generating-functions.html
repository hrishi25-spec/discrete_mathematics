06 Generating Functions

1. Why this topic matters

Generating functions turn recurrence and counting problems into algebra. Instead of manipulating sequences term by term, you manipulate a single power series and read off coefficients. Fibonacci, redundant combinations, and partitions all become simple rational functions. The skill is setting up the series correctly and extracting the coefficient.

2. Prerequisites

Sequences and recurrences from page 01 and page 05; basic counting from page 02.

3. Intuition

A generating function is a clothesline: hang the sequence terms as coefficients of powers of x. Multiplying series corresponds to combining independent choices, so counting problems become polynomial multiplication. The picture below shows Fibonacci terms hanging on the line.

4. Definitions

Ordinary generating function: for sequence a_0,a_1,..., G(x)=Σ_{n≥0} a_n x^n.

Coefficient extraction: [x^n]G(x)=a_n.

Geometric series: 1/(1-x)=1+x+x^2+... .

Derivative/integral and shifts: multiplying by x shifts indices; these are the main algebraic tools.

5. Theorems and complete proofs

Theorem: Fibonacci generating function

If F_0=0, F_1=1, F_n=F_{n-1}+F_{n-2}, then G(x)=x/(1-x-x^2). Exam likely.

Proof. G=F_0+F_1 x+Σ_{n≥2}F_n x^n = x+Σ_{n≥2}(F_{n-1}+F_{n-2})x^n = x+xΣ_{n≥2}F_{n-1}x^{n-1}+x^2Σ_{n≥2}F_{n-2}x^{n-2} = x+x(G-F_0)+x^2 G = x+xG+x^2G. Hence G(1-x-x^2)=x. ∎

Theorem: redundant combinations via generating functions

The number of multisets of size r from n types is C(n+r-1,r), and its generating function is 1/(1-x)^n.

Proof. Each type contributes 1+x+x^2+...=1/(1-x). Multiplying n types gives 1/(1-x)^n. The coefficient of x^r is (−1)^r C(-n,r)=C(n+r-1,r). ∎

Theorem: compositions with order counting

The number of compositions of n into exactly r positive parts is C(n-1,r-1), with generating function (x/(1-x))^r.

Proof. Each part is x+x^2+...=x/(1-x). Multiplying r parts gives x^r/(1-x)^r. Coefficient of x^n is coefficient of x^{n-r} in (1-x)^{-r}, namely C(n-1,r-1). ∎

Theorem: binomial series

(1-x)^{-r}=Σ_{m≥0} C(r+m-1,m) x^m.

Proof. This is the generalized binomial theorem with exponent -r. ∎

6. Worked examples

Example 1

For sequence 1,5,19,65,... with a_n=5a_{n-1}-6a_{n-2}, set up G(x)=a_0+a_1 x+... and solve G(x)= (a_0+(a_1-5a_0)x)/(1-5x+6x^2). With a_0=1,a_1=5, G(x)=1/(1-5x+6x^2).

Example 2

Coefficient of x^4 in (1-x)^{-3} is C(3+4-1,4)=C(6,4)=15.

Example 3

Compositions of 7 into 4 parts: C(6,3)=20.

Example 4

Fibonacci generating function G=x/(1-x-x^2); coefficient of x^5 is F_5=5.

Example 5

Constrained selection: 4 fruits with pomegranate and banana at most 1, mango at most 2, oranges unrestricted: multiply (1+x)(1+x)(1+x+x^2)(1+x+x^2+x^3+x^4); coefficient of x^4 gives the count (Python can extract).

9. Common mistakes and exam traps

  • Forgetting the initial terms when shifting series.
  • Using ordinary generating functions where exponential generating functions are needed (not in this course).
  • Misreading coefficient extraction after multiplying by x.
  • Not factoring the denominator before partial fractions.

10. Practice questions (assigned to this page)

Q13. Generating function for partitions into exactly r parts where order counts; find compact form A(n,r).

Solution: G(x)=(x/(1-x))^r=x^r/(1-x)^r. Coefficient of x^n is C(n-1,r-1). Python verification for n=7,r=4 gives C(6,3)=20.

12. Cheat sheet

G(x)=Σ a_n x^n. 1/(1-x)=Σ x^n.

Fibonacci: x/(1-x-x^2).

Redundant combinations: 1/(1-x)^n; coeff C(n+r-1,r).

Compositions: x^r/(1-x)^r; coeff C(n-1,r-1).

Shift: xG(x) shifts indices by 1.
