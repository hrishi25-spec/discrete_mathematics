03 Occupancy Problem, Stirling Numbers of the 2nd Kind, Surjections

1. Why this topic matters

Occupancy problems ask how many ways n balls can be placed into k cells under different distinguishability and emptiness rules. The table unifies k^n, combinations, Stirling numbers, and surjections in one place. The Stirling recurrence S(n,k)=k S(n-1,k)+S(n-1,k-1) is a standard exam question, and Sur(n,k)=k! S(n,k) connects counting to set partitions.

2. Prerequisites

Basic counting and stars and bars from page 02; inclusion-exclusion for surjections from page 04.

3. Intuition

Imagine distributing n distinct balls into k boxes. If boxes are distinguishable, each ball has k independent choices. If boxes are indistinguishable, only the grouping of balls matters, which is a set partition. The picture below shows 3 distinct balls split into 2 unlabeled groups.

4. Definitions

Occupancy problem: distribute n balls into k cells, depending on whether balls/cells are distinguishable and whether empty cells are allowed.

Surjection Sur(n,k): number of onto functions from an n-set to a k-set.

Stirling number of the 2nd kind S(n,k): number of partitions of an n-set into exactly k nonempty unlabeled subsets.

Base values: S(n,0)=0 for n>0, S(n,1)=1, S(n,n)=1, S(n,n-1)=C(n,2), S(n,2)=2^{n-1}-1.

5. Theorems and complete proofs

Theorem: occupancy table (distinguishable balls and cells)

If balls and cells are distinguishable and empty cells allowed, count is k^n. If no empty cells, count is Sur(n,k). Exam likely.

Proof. Each of n balls independently chooses one of k cells: k^n. For no empty cells, exclude missing cells by inclusion-exclusion: Sur(n,k)=Σ_{i=0}^k (-1)^i C(k,i)(k-i)^n. ∎

Theorem: occupancy with indistinguishable cells

If balls are distinguishable and cells indistinguishable: empty allowed gives Σ_{i=1}^k S(n,i); no empty gives S(n,k).

Proof. A distribution into i nonempty unlabeled cells is exactly a partition of the n balls into i blocks; sum over i for empty allowed. ∎

Theorem: Stirling recurrence

S(n,k)=k S(n-1,k)+S(n-1,k-1). Exam likely.

Proof. Partition {1,...,n} into k blocks. If n is in a block with others, remove it and choose which of the k blocks it rejoins: k S(n-1,k). If n is alone, partition the rest into k-1 blocks: S(n-1,k-1). ∎

Theorem: Stirling closed form via generating functions

S(n,k) = 1/k! Σ_{j=0}^k (-1)^{k-j} C(k,j) j^n. (Not in slides - standard result.)

Proof. The generating function for fixed k is f_k(x)=x^k/((1-x)(1-2x)...(1-kx)); partial fractions give the closed form. ∎

Theorem: surjections via Stirling numbers

Sur(n,k)=k! S(n,k). Exam likely.

Proof. S(n,k) counts partitions into unlabeled cells. Label the k cells in k! ways to make the cells distinguishable. ∎

Theorem: stars and bars (indistinguishable balls, distinguishable cells)

If balls are indistinguishable and cells distinguishable: empty allowed gives C(n+k-1,k-1); no empty gives C(n-1,k-1).

Proof. Weak compositions of n into k parts; standard stars and bars. ∎

6. Worked examples

Example 1

Sur(5,4)=4^5−4·3^5+6·2^5−4·1^5=240.

Example 2

S(5,3)=3·S(4,3)+S(4,2)=3·6+7=25.

Example 3

Number of ways to put 7 distinct balls into 3 identical boxes allowing empty: S(7,1)+S(7,2)+S(7,3)=1+63+301=365.

Example 4

Number of surjections from 4 elements to 4 elements is 4! = 24, and indeed S(4,4)=1, so 4!·1=24.

Example 5

Distribute 10 identical chocolates into 3 distinct kids: C(10+3−1,3−1)=C(12,2)=66.

9. Common mistakes and exam traps

  • Confusing S(n,k) (unlabeled cells) with Sur(n,k) (labeled cells).
  • Forgetting Sur(n,k)=k! S(n,k), not S(n,k)/k!.
  • Using k^n when empty cells are forbidden.
  • Forgetting S(n,2)=2^{n-1}-1.
  • Mixing up balls vs cells distinguishability.

10. Practice questions (assigned to this page)

Q7. How many surjective maps from a 5-element set to a 4-element set?

Solution: Sur(5,4)=4^5−4·3^5+6·2^5−4·1^5=1024−972+192−4=240. Python verification: 240.

12. Cheat sheet

Distinguishable balls/cells, empty allowed: k^n.

Surjection: Sur(n,k)=Σ (-1)^i C(k,i)(k-i)^n = k! S(n,k).

Stirling recurrence: S(n,k)=k S(n-1,k)+S(n-1,k-1).

Base: S(n,2)=2^{n-1}-1, S(n,n-1)=C(n,2), S(n,n)=1.

Indistinguishable balls, distinct cells, empty allowed: C(n+k-1,k-1).

No empty: C(n-1,k-1).
