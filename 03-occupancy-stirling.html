03 Occupancy Problem, Stirling Numbers of the 2nd Kind, Surjections

1. Why this topic matters

Occupancy problems ask how many ways n balls can be placed into k cells under different distinguishability and emptiness rules. The table unifies k^n, combinations, Stirling numbers, and surjections in one place. The Stirling recurrence S(n,k)=k S(n-1,k)+S(n-1,k-1) is a standard exam question, and Sur(n,k)=k! S(n,k) connects counting to set partitions.

Basic counting and stars and bars from page 02; inclusion-exclusion for surjections from page 04.

3. Intuition

Imagine distributing n distinct balls into k boxes. If boxes are distinguishable, each ball has k independent choices, so the answer is kn (occupancy, Theorem 1). If boxes are indistinguishable, only the grouping of balls matters, which is a set partition, counted by the Stirling number S(n,k) (Theorem 3). 4. Definitions

Occupancy problem: distribute n balls into k cells, depending on whether balls/cells are distinguishable and whether empty cells are allowed.

Surjection Sur(n,k): number of onto functions from an n-set to a k-set.

Stirling number of the 2nd kind S(n,k): number of partitions of an n-set into exactly k nonempty unlabeled subsets.

Base values: S(n,0)=0 for n>0, S(n,1)=1, S(n,n)=1, S(n,n-1)=C(n,2), S(n,2)=2^{n-1}-1.

5. Theorems and complete proofs

Every counting fact on this page is proved from the sum and product rules; the proofs below are the full step-by-step versions that appear in exams.

Theorem: occupancy table (distinguishable balls and cells)

Exam likely. If balls and cells are distinguishable and empty cells are allowed, the count is kn. If no empty cell may occur, the count is the number of surjections Sur(n,k).

Part 1 — placements with empty cells allowed: kn

  1. Model the placement. A placement is a function f from the set of n balls to the set of k cells, where f(ball) names the cell that ball occupies.
  2. Each ball chooses independently. The cells are distinguishable and no cell is excluded yet, so ball 1 has k choices, ball 2 has k choices, and so on; the choice of one ball never removes an option from another.
  3. Apply the product rule. The placement is assembled ball by ball, so the count is k·k···k (n factors) = kn.
  4. Check the small cases. One ball into k cells gives k; two balls into k cells give k2. ∎

Part 2 — no empty cells: the surjection formula

  1. Start from all functions. With empty cells allowed there are kn functions from an n-set to a k-set.
  2. Count the bad ones for a fixed set of empty cells. For a fixed set J of i cells that must stay empty, the surviving functions are the maps into the remaining k−i cells, so there are (k−i)n of them; the number of such sets J is C(k,i).
  3. Apply inclusion–exclusion. Alternating over the subsets of cells gives the surjection count Sur(n,k) = Σi=0k (−1)i C(k,i)(k−i)n.
  4. Justify the alternating sum. A function missing exactly t cells is counted by Σi=0t (−1)i C(t,i) = (1−1)t, which is 1 when t=0 and 0 otherwise, so only functions hitting every cell survive. ∎

Theorem: occupancy with indistinguishable cells

If the balls are distinguishable but the cells are indistinguishable, the answer depends on the emptiness rule.

  1. Empty cells allowed. A placement into at most k nonempty groups is a partition of the n balls into between 1 and k blocks, so the total is Σi=1k S(n,i).
  2. No empty cells. A placement into exactly k nonempty groups is a partition into exactly k blocks, namely S(n,k).
  3. Why Stirling numbers. With indistinguishable cells, permuting block labels gives the same placement, which is why the labelled surjection count is replaced by the Stirling number. ∎

Theorem: Stirling recurrence

Exam likely.

  1. Fix the ground set {a1,…,an} and the block count k.
  2. Case 1 — an is alone. Remove it; the remaining n−1 elements must be partitioned into k−1 blocks, giving S(n−1,k−1).
  3. Case 2 — an joins an existing block. Partition the first n−1 elements into k blocks (there are S(n−1,k)), then let an join any of those k blocks: k·S(n−1,k).
  4. Add the disjoint cases. Both cases cover all partitions, so S(n,k) = k·S(n−1,k) + S(n−1,k−1). ∎

Check n=5, k=3: S(5,3) = 3·S(4,3) + S(4,2) = 3·6 + 7 = 25 (example 4).

Theorem: Stirling closed form via generating functions

S(n,k) = (1/k!) Σj=0k (−1)k−j C(k,j) jn. Not in slides - standard result.

  1. Write the generating function for a fixed k. Σn S(n,k) xn = xk / ((1−x)(1−2x)···(1−kx)).
  2. Partial fractions. Decompose the right side into terms of the form Aj / (1−jx).
  3. Extract the coefficient. The coefficient of xn is Aj·jn, and collecting over the k terms gives the stated closed form. ∎

Theorem: surjections via Stirling numbers

Exam likely.

  1. Start from the partition count. S(n,k) counts partitions of an n-set into exactly k nonempty unlabeled blocks.
  2. Lay the blocks over the cells. A surjection assigns every ball to one of k labelled cells, which is the same object with the blocks labelled.
  3. Count the labelings. The k labels can be spread over the k blocks in k! ways.
  4. Conclude. Therefore Sur(n,k) = k!·S(n,k). ∎

Theorem: stars and bars (indistinguishable balls, distinguishable cells)

If the balls are indistinguishable and the cells are distinguishable, empty cells allowed gives the weak compositions of n into k nonnegative parts; no empty cells gives the compositions into k positive parts.

  1. Encode a solution as stars and bars. A solution y1+…+yk=n with yi≥0 becomes a picture with n stars and k−1 bars.
  2. Read off the solution. The stars between consecutive bars give the yi, so the map is injective and surjective — a bijection.
  3. Count the pictures. Choosing the k−1 bar positions among the n+k−1 positions gives C(n+k−1, k−1) weak compositions.
  4. Strictification for positive parts. Requiring every part ≥1 is the same as subtracting 1 from each part; the count becomes C(n−1, k−1) compositions. ∎

6. Worked examples

Example 1 (easy): 4 distinct balls into 3 distinct cells, empty cells allowed

Each of the 4 balls chooses one of the 3 cells independently, so by the product rule (Theorem 1, Part 1) the count is 3·3·3·3 = 34 = 81. Empty cells are allowed, so a cell may simply receive no ball.

Example 2 (easy): surjections from a 4-element set to a 4-element set

Every element maps onto the single cell, so the only surjection is the identity: Sur(4,4) = 4!·S(4,4) = 4!·1 = 24. Check by inclusion–exclusion: Sur(4,4) = Σi=04 (−1)i C(4,i)(4−i)4 = 44 − 4·34 + 6·24 − 4·14 = 256 − 324 + 96 − 4 = 24. ✔

Example 3 (easy): 10 identical chocolates into 3 distinct kids, empty cells allowed

Weak stars and bars (Theorem 6): the number of solutions to y1+y2+y3=10 in nonnegative integers is C(10+3−1,3−1)=C(12,2)=(12·11)/(2·1)=66; each solution is one picture of 10 stars and 2 bars, and a kid may receive no chocolate.

Example 4 (medium): Stirling number S(5,3)

By the recurrence (Theorem 3): S(5,3) = 3·S(4,3) + S(4,2). Working the triangle up: S(4,3) = 3·S(3,3) + S(3,2) = 3·1 + 3 = 6; S(4,2) = 2·S(3,2) + S(3,1) = 2·3 + 1 = 7. Hence S(5,3) = 3·6 + 7 = 25. Cross-check with the closed form (Theorem 4): (1/3!)·(35 − 3·25 + 3·15) = (243 − 96 + 3)/6 = 150/6 = 25. ✔

Example 5 (medium): 7 distinct balls into 3 identical boxes allowing empty

Sum the Stirling numbers over the possible block counts: S(7,1) + S(7,2) + S(7,3) = 1 + 63 + 301 = 365. Full working: S(7,1)=1 (all 7 balls in one block); S(7,2)=26−1=63; S(7,3)=301 (by the closed form). ✔

Example 6 (medium–hard): surjections from a 5-element set to a 4-element set

By inclusion–exclusion (Theorem 1, Part 2): Sur(5,4) = Σi=04 (−1)i C(4,i)(4−i)5 = 45 − 4·35 + 6·25 − 4·15 = 1024 − 972 + 192 − 4 = 240. This is practice question Q7. ✔

Example 7 (hard): surjections from a 5-element set to a 2-element set

Two cells, both must be hit. Via Stirling (Theorem 5): S(5,2) = 24−1 = 15, so Sur(5,2) = 2!·S(5,2) = 2·15 = 30. Check by inclusion–exclusion: Sur(5,2) = 25 − 2·15 = 32 − 2 = 30. ✔

9. Common mistakes and exam traps

  1. Using kn when empty cells are forbidden. Wrong: 2 distinct balls into 2 cells, no empty cell allowed → 22 = 4. Right: Sur(2,2) = 2 functions (the two bijections), because both cells must be hit. The product rule counted the empty-cell placements too.
  2. Forgetting the factor k! in Sur(n,k) = k!S(n,k). Wrong: answer Sur(5,4) = S(5,4) = 10. Right: Sur(5,4) = 4!·S(5,4) = 24·10 = 240, because the Stirling blocks are unlabeled but the surjection cells are labelled.
  3. Using the Stirling recurrence on labelled cells. Wrong: 3 distinct balls into 2 distinct kids, no empty kid → C(3−1,2−1) = C(2,1) = 2 (stars and bars, which assumes indistinguishable balls). Right: Sur(3,2) = 2!·S(3,2) = 2·3 = 6.
  4. Adding Stirling numbers when the question asks for placements with empty cells allowed. Wrong: 4 distinct balls into 2 identical cells, no empty cell → S(4,2) = 7. Right: empty allowed → Σi=12 S(4,i) = S(4,1)+S(4,2) = 1+7 = 8.
  5. Confusing weak and strict compositions. Wrong: 10 identical chocolates into 3 distinct kids, no kid empty → C(10+3−1,3−1) = C(12,2) = 66. Right: strict composition → C(10−1,3−1) = C(9,2) = 36 (give one to each kid first, then distribute the rest).
  6. Adding instead of applying inclusion–exclusion. Wrong: Sur(5,4) ≈ 45 − 4·35 − 6·25 = 1024 − 972 − 192 = −140 (wrong sign/double counting). Right: 45 − 4·35 + 6·25 − 4·15 = 240.

10. Practice questions (assigned to this page)

Q7. How many surjective maps are there from a 5-element set to a 4-element set?

Reading the question. A map from a 5-element set onto a 4-element set must hit every one of the 4 elements, so no cell may be left empty.

Step 1. With empty cells allowed there are 45 = 1024 maps (product rule, Theorem 1).

Step 2. Subtract the maps that miss at least one cell, using inclusion–exclusion (Theorem 1, Part 2): Sur(5,4) = Σi=04 (−1)i C(4,i)(4−i)5.

Step 3. Evaluate: 45 − 4·35 + 6·25 − 4·15 = 1024 − 972 + 192 − 4 = 240.

Step 4. Cross-check with Stirling: Sur(5,4) = 4!·S(5,4) = 24·10 = 240, and S(5,4) came from the recurrence in example 4. ✔

11. Extra self-test questions

1. How many placements of 4 distinct balls into 2 distinct cells allow empty cells?

Product rule (Theorem 1, Part 1): 24 = 16.

2. How many surjections are there from a 5-element set to a 3-element set?

Inclusion–exclusion (Theorem 1, Part 2): Sur(5,3) = 35 − 3·25 + 3·15 = 243 − 96 + 3 = 150.

3. What is S(6,3)?

Closed form (Theorem 4): S(6,3) = (1/3!)·(36 − 3·26 + 3·16) = (729 − 192 + 3)/6 = 540/6 = 90.

4. How many partitions of a 6-element set into exactly 2 blocks are there?

S(6,2) = 25−1 = 31 (base value, Theorem 3).

5. How many ways to put 5 distinct balls into 2 identical cells with no empty cell?

Stirling (Theorem 3): S(5,2) = 24−1 = 15.

6. How many weak compositions of 8 into 3 parts are there?

Stars and bars (Theorem 6): C(8+3−1,3−1) = C(10,2) = 45.

7. How many compositions of 8 into exactly 3 positive parts are there?

Strict composition (Theorem 6): C(8−1,3−1) = C(7,2) = 21.

8. How many ways to distribute 6 distinct balls into 3 distinct cells with no empty cell?

Sur(6,3) = 36 − 3·26 + 3·16 = 729 − 192 + 3 = 540.

12. Cheat sheet

Definitions

  • Occupancy problem: distribute n balls into k cells; depends on ball/cell distinguishability and whether empties are allowed.
  • Surjection Sur(n,k): onto functions from an n-set to a k-set.
  • Stirling number S(n,k): partitions of an n-set into exactly k nonempty unlabeled blocks.
  • Base values: S(n,0)=0 (n>0), S(n,1)=1, S(n,n)=1, S(n,n−1)=C(n,2), S(n,2)=2^{n−1}−1.

Theorems

  • Occupancy, distinguishable balls/cells, empties allowed: kn.
  • Surjection: Sur(n,k) = Σi=0k (−1)i C(k,i)(k−i)n = k!S(n,k).
  • Occupancy, distinguishable balls/identical cells, empties allowed: Σi=1k S(n,i); no empties: S(n,k).
  • Stirling recurrence: S(n,k) = k·S(n−1,k) + S(n−1,k−1).
  • Stirling closed form: S(n,k) = (1/k!) Σj=0k (−1)k−j C(k,j) jn.
  • Stars and bars: weak compositions of n into k parts = C(n+k−1, k−1); strict compositions into k positive parts = C(n−1, k−1).

Exam checklist

  1. Are the balls distinguishable? If no, do not use surjections or Stirling numbers — use stars and bars.
  2. Are the cells distinguishable? If no, use Stirling numbers, not surjections.
  3. May cells be empty? Yes → kn or ΣS(n,i); no → Sur(n,k) or S(n,k).
  4. Is the question "onto"? Then inclusion–exclusion or k!·S(n,k).
  5. Is it "at most k blocks"? Then ΣS(n,i).
  6. Is it weak (empties allowed) or strict (no empties)? Weak → C(n+k−1,k−1); strict → C(n−1,k−1).
