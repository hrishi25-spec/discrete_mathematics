13 Trees, Prüfer Codes, Spanning Trees, Kruskal, Prim, Dijkstra, Rooted and Binary Trees

1. Why this topic matters

Trees are the minimal connected graphs and appear in networks, parsing, coding, and optimization. Prüfer codes give an exact count of labeled trees, while Kruskal, Prim, and Dijkstra are the standard algorithms for MST and shortest paths. The exam often asks for proofs of correctness and step-by-step algorithm execution.

3. Intuition

A tree is a connected graph with no cycles; it has n-1 edges. Removing any edge disconnects it, and adding any edge creates a cycle. The picture below is a tree on 5 vertices.

4. Definitions

Tree: connected acyclic graph.

Forest: acyclic graph.

Leaf: vertex of degree 1.

Spanning tree: spanning subgraph that is a tree.

MST: spanning tree of minimum total edge weight.

Prüfer code: sequence of n-2 labels encoding a labeled tree.

Rooted tree: tree with a designated root; parent/child/ancestor/descendant.

Binary tree: rooted plane tree with at most two children, left/right.

5. Theorems and complete proofs

Theorem: tree characterizations

For an n-vertex graph (n>1), the following are equivalent: connected and acyclic; connected with n-1 edges; acyclic with n-1 edges; exactly one path between every pair. Exam likely.

Proof. A tree with at least two vertices has a leaf (endpoint of a maximal path). Remove the leaf and its incident edge; the remainder is a tree on n-1 vertices. By induction it has n-2 edges, so the original has n-1 edges. Conversely a connected graph with n-1 edges is acyclic, and an acyclic graph with n-1 edges is connected. ∎

Theorem: number of labeled trees

There are n^{n-2} labeled trees on n vertices. Exam likely.

Proof. The encoding repeatedly removes the smallest leaf and records its neighbour; decoding reverses this by attaching the smallest label not in the remaining code. These maps are inverses, so labeled trees biject with sequences of length n-2 over [n], giving n^{n-2}. ∎

Theorem: Kruskal's algorithm correctness

Kruskal's algorithm produces an MST.

Proof. Let e be the first edge chosen for T that is not in an MST T*. Adding e to T* creates a cycle C. Since T is acyclic, C contains an edge e' not in T. When e was chosen, e' was available, so w(e)≤w(e'). Thus T*+e-e' is a spanning tree of weight at most w(T*) that agrees with T on a longer initial segment. Repeating yields an MST equal to T. ∎

Theorem: Prim's algorithm correctness

Prim's algorithm produces an MST. Exam likely (Q40).

Proof. Let S be the set of reached vertices and let e=uv be the cheapest edge with u∈S, v∉S. Any spanning tree must contain some edge crossing this cut; if it does not contain e, replacing its crossing edge by e does not increase weight. Thus e is in an MST. ∎

Theorem: Dijkstra's algorithm

Dijkstra computes shortest path distances from a source in a graph with nonnegative weights.

Proof. Induct on |S|. The selected vertex has smallest tentative distance; any path to it through an unfinalized vertex is at least as long because edge weights are nonnegative, so its distance is final. ∎

Theorem: every tree has at most one perfect matching

Every tree has at most one perfect matching. Exam likely (Q44).

Proof. If two perfect matchings differed, their symmetric difference would be a nonempty union of even cycles in the tree, impossible. ∎

Theorem: tree is 2-colourable

Every tree is bipartite. Exam likely (Q36).

Proof. Colour vertices by parity of distance from an arbitrary root; edges connect opposite parities. ∎

6. Worked examples

Example 1: Prüfer code count

Number of labeled trees on 6 vertices = 6^{4}=1296.

Example: Prüfer decode

Decode ⟨1,1,5⟩ on 6 vertices by repeatedly attaching the smallest missing label to the first code entry, then joining the last two labels.

9. Common mistakes and exam traps

  • Forgetting MST may not be unique, but weight is unique.
  • Using Prim/Kruskal with negative weights (not in this course).
  • Prüfer code length is n-2, not n.
  • Confusing rooted tree parent/child orientation.
  • Assuming every tree has a perfect matching.
