08 Catalan Numbers and Lattice Paths

1. Why this topic matters

Catalan numbers count parenthesizations, triangulations, Dyck paths, and many other recursively decomposable structures. The reflection principle is the key technique for counting paths that stay on one side of a diagonal. Exam questions usually ask for Catalan C_n or for a reflection-principle count.

2. Prerequisites

Basic counting and combinations from page 02.

3. Intuition

Consider monotone paths from (0,0) to (n,n) using steps east and north. Total paths are C(2n,n). "Good" paths never rise above the diagonal y=x. A bad path first touches the line y=x+1; reflect the rest of that path across the line to get a path to (n−1,n+1). This bijection counts bad paths as C(2n,n−1), so the good ones number C(2n,n)−C(2n,n−1) = Cn. The first picture shows a good path; the second shows a bad path and its reflection.

4. Definitions

Monotone lattice path: path from (0,0) to (a,b) using east and north steps.

Catalan number: C_n = (1/(n+1)) C(2n,n).

Bad path: path from (0,0) to (n,n) that at some point has y > x (goes above diagonal).

Reflection principle: reflect part of a path after first crossing a boundary to count bad paths.

5. Theorems and complete proofs

Each proof is written in numbered steps, with the inverse map or the simplifying algebra shown explicitly.

Theorem: number of monotone paths

Paths from (0,0) to (a,b) using east and north steps number C(a+b,a). Exam likely.

  1. List the steps. Every monotone path consists of exactly a east steps and b north steps, in some order, so it has a+b steps.
  2. Encode by a choice of positions. Once the a positions occupied by east steps are known, the remaining b positions are north steps and the path is determined.
  3. Count. The number of ways to choose those positions is C(a+b,a), and different choices give different paths. ∎

Theorem: reflection principle (general)

Bad paths from (0,0) to (n,n) that touch or cross y=x+1 are in bijection with all paths from (0,0) to (n−1,n+1).

  1. Locate the first touch. For a bad path, let P be the first vertex with y=x+1. It exists because the path ends with y=x but was above at some point.
  2. Reflect the suffix. Send each later vertex (x,y) to (y−1,x+1), reflection in the line y=x+1. East and north steps swap, so the reflected suffix is still a monotone path, and the endpoint (n,n) becomes (n−1,n+1).
  3. Construct the inverse. Start from any path to (n−1,n+1). It begins below y=x+1 (at the origin) and ends above it, so it has a first touch with that line; reflecting the suffix back recovers a bad path to (n,n).
  4. Conclusion. The two maps undo each other, so the number of bad paths is the number of paths to (n−1,n+1), namely C(2n,n−1). ∎

Theorem: Catalan number

Cn = C(2n,n) − C(2n,n−1) = (1/(n+1))C(2n,n). Exam likely.

  1. Count all paths. By the first theorem, there are C(2n,n) monotone paths from (0,0) to (n,n).
  2. Subtract the bad ones. By the reflection principle, C(2n,n−1) of them go above the diagonal, so Cn = C(2n,n) − C(2n,n−1).
  3. Simplify. C(2n,n−1) = C(2n,n)·n/(n+1), so the difference is C(2n,n)(1−n/(n+1)) = C(2n,n)/(n+1). ∎

Theorem: Catalan recurrence and parenthesizations

The lecture notes give this recurrence; its solution is the Catalan number defined above.

  1. Base case. A product of one factor needs no parentheses, so a0=1; the notes also set a1=1.
  2. Look at the last multiplication. Any full parenthesization of x0…xn has a outermost product splitting the factors into a left block of i+1 factors and a right block of n−i factors.
  3. Count one split. The left block can be parenthesized in ai ways, the right in an−1−i ways, and these choices are independent: aian−1−i ways.
  4. Sum over splits. The splits are disjoint and exhaustive, giving the recurrence; its solution is an=Cn. ∎

6. Worked examples

Example 1 (easy): monotone paths to (3,5)

A path from (0,0) to (3,5) has 3 east and 5 north steps, so 8 steps in all. Choose the 3 positions of the east steps: C(8,3) = (8·7·6)/(3·2·1) = 56.

Example 2 (easy): the third Catalan number

C3 = C(6,3)−C(6,2) = 20−15 = 5, which also equals (1/4)C(6,3) = 20/4 = 5.

Example 3 (easy): parenthesizing four factors

Four factors x0x1x2x3 have C3=5 parenthesizations: ((x0x1)(x2x3)), (((x0x1)x2)x3), (x0(x1(x2x3))), ((x0(x1x2))x3), (x0((x1x2)x3)).

Example 4 (medium): good and bad paths for n=6

All paths from (0,0) to (6,6): C(12,6)=924. Bad paths: C(12,5)=792. Hence good paths = 924−792=132 = C6 (also (1/7)·924=132).

Example 5 (medium): parenthesizing five factors

Five factors give C4 = C(8,4)−C(8,3) = 70−56 = 14 ways, matching the recurrence a4=a0a3+a1a2+a2a1+a3a0 = 5+2+2+5 = 14.

Example 6 (hard): cross the diagonal exactly once

For a path from (0,0) to (6,6), "cross" means the sign of y−x changes once. Split at the diagonal point (k,k) where the change happens. The part before stays weakly on one side: Ck ways; the part after stays weakly on the other: C6−k ways. Either order is possible, so for k=1,…,5 the count is 2ΣCkC6−k = 2(1·42 + 2·14 + 5·5 + 14·2 + 42·1) = 2·165 = 330. Brute-force enumeration of all 924 paths confirms 330.

Example 7 (hard): touch the diagonal at exactly one interior point

Reading "cross" as "touch at one interior vertex" gives a different answer. Choose the interior touch (k,k), 1≤k≤5. A path from (0,0) to (k,k) with no interior diagonal visit is strictly above or strictly below throughout, so 2Ck−1 ways; similarly 2C5−k ways for the rest. Total 4Σk=15 Ck−1C5−k = 4C5 = 4·42 = 168, confirmed by enumeration. Both readings of Q26 are stated on this page.

9. Common mistakes and exam traps

  1. Confusing "cross" with "touch" (Q26). Wrong: answer 168 to "changes sides exactly once". Right: 330 for a sign change, 168 for an interior touch at a single point. Both readings are stated in example 7 and Q26.
  2. Using all paths instead of good paths. Wrong: paths from (0,0) to (6,6) staying on one side = C(12,6)=924. Right: C6=924−792=132.
  3. Reflecting across the wrong line. Wrong: reflect across y=x, which fixes the endpoint (6,6), giving bad paths = C(12,6)=924. Right: first touch is y=x+1, so bad paths = C(12,5)=792.
  4. Forgetting the 1/(n+1) factor. Wrong: parenthesizations of 5 factors = C(8,4)=70. Right: C4 = 70/(4+1) = 14.
  5. Off-by-one in the Catalan index. Wrong: 4 factors give C4=14. Right: n+1 factors give Cn, so 4 factors give C3=5.
  6. Swapping good and bad counts. Wrong: bad paths for n=6 number 132. Right: bad = C(12,5)=792, good = C(12,6)−C(12,5)=132.
  7. Adding both binomial choices for a path. Wrong: paths to (3,5) = C(8,3)+C(8,5) = 112. Right: choosing the east positions or the north positions describes the same paths, so the answer is just C(8,3)=56.

10. Practice questions (assigned to this page)

Q26. Find the number of progressing paths from (0,0) to (6,6) which cross the diagonal exactly once.

Reading A — "cross" means change sides.

Step 1. Decompose the path at its visits to the diagonal. Between visits it stays strictly on one side, so each excursion has a sign: above or below.

Step 2. If the sign changes exactly once, there is a diagonal point (k,k), 1≤k≤5, where the above-excursions end and the below-excursions begin, or the reverse.

Step 3. A sequence of above-excursions from (0,0) to (k,k) is exactly a path staying weakly above the diagonal: Ck ways. The remaining below-excursions give C6−k ways.

Step 4. Either order is possible, so the count is 2Σk=15 CkC6−k = 2(1·42 + 2·14 + 5·5 + 14·2 + 42·1) = 2·165 = 330. Enumeration of all C(12,6)=924 paths confirms 330.

Reading B — "cross" means touch the diagonal at exactly one interior point.

Step 5. Choose the interior touch (k,k). A path from (0,0) to (k,k) with no earlier diagonal visit is strictly above or strictly below, giving 2Ck−1 ways; the remaining segment gives 2C5−k.

Step 6. Total = 4Σk=15 Ck−1C5−k = 4C5 = 4·42 = 168, also confirmed by enumeration.

Conclusion. State which reading is intended: 330 for an actual change of sides, 168 for a single interior touch.

11. Extra self-test questions

1. What is C4?

C4 = C(8,4)−C(8,3) = 70−56 = 14, equivalently (1/5)C(8,4) = 70/5 = 14.

2. Paths from (0,0) to (2,4)?

There are 2 east and 4 north steps, 6 in all, so C(6,2) = (6·5)/(2·1) = 15.

3. Bad paths for n=4?

Bad paths first touch y=x+1 and correspond to paths to (3,5), so there are C(8,3)=56. The good ones are C(8,4)−C(8,3)=14.

4. Parenthesizations of 5 factors?

Five factors give C4 = 14 ways, matching the recurrence 5+2+2+5 = 14.

5. Good paths for n=3?

C3 = C(6,3)−C(6,2) = 20−15 = 5.

6. Paths from (0,0) to (4,7)?

Eleven steps, of which 4 are east, so C(11,4) = (11·10·9·8)/(4·3·2·1) = 7920/24 = 330.

7. What is C5?

C5 = C(10,5)−C(10,4) = 252−210 = 42, equivalently 252/6 = 42.

8. Paths from (0,0) to (6,6) that never go above the diagonal?

These are the Catalan paths: C6 = C(12,6)−C(12,5) = 924−792 = 132.

12. Cheat sheet

Definitions

  • Monotone lattice path: from (0,0) to (a,b) with east and north steps.
  • Bad path: from (0,0) to (n,n) that at some point has y>x.
  • Catalan number: Cn = (1/(n+1))C(2n,n).
  • Reflection principle: reflect the part of a path after its first touch of a boundary line.

Formulas

  • Paths (0,0)→(a,b): C(a+b,a).
  • Total paths to (n,n): C(2n,n).
  • Bad paths: C(2n,n−1) (reflect across y=x+1 to (0,0)→(n−1,n+1)).
  • Cn = C(2n,n) − C(2n,n−1) = C(2n,n)/(n+1).
  • Catalan recurrence: a0=1, an = Σi=0n−1 aian−1−i.
  • Parenthesizations of n+1 factors, triangulations of an (n+2)-gon, and non-crossing handshake pairings of 2n people: Cn.
  • Change sides exactly once from (0,0) to (n,n): 2Σk=1n−1 CkCn−k.
  • Exactly one interior diagonal touch: 4Cn−1.

Exam checklist

  1. Count the total paths first with C(a+b,a).
  2. For a diagonal condition, locate the first touch of y=x+1.
  3. Reflect the suffix, not the whole path.
  4. Use the factor 1/(n+1) for Catalan numbers.
  5. Decide whether "cross" means change sides or touch; verify both if needed.
