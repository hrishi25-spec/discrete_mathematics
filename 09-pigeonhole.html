09 Pigeonhole Principle

1. Why this topic matters

The pigeonhole principle is a simple but powerful counting/contradiction tool: if more objects than boxes, some box has at least two. It proves non-injectivity, guarantees collisions, and underlies the birthday paradox. Many exam problems are one-line applications once you identify the pigeons and holes.

2. Prerequisites

Basic counting from page 02; inclusion-exclusion for collision counts from page 04.

3. Intuition

If 6 pigeons go into 5 holes, at least one hole has at least 2 pigeons. The proof is by contradiction: if every hole had at most 1, there would be at most 5 pigeons. The picture below shows 6 balls in 5 boxes.

4. Definitions

Pigeonhole principle: if n+1 objects are placed in n boxes, some box contains at least 2 objects.

Generalized form: if nk+1 objects are placed in n boxes, some box contains at least k+1 objects.

Empty box form: if n-1 objects are placed in n boxes, some box is empty.

5. Theorems and complete proofs

Theorem: basic pigeonhole principle

If n+1 pigeons are placed in n holes, one hole has more than 1 pigeon. Exam likely.

Proof (contraposition). If every hole has at most 1 pigeon, then total pigeons ≤ n, contradiction. ∎

Theorem: generalized pigeonhole principle

If nk+1 objects are placed in n boxes, some box has at least k+1 objects.

Proof. If every box had at most k objects, total would be at most nk, contradiction. ∎

Theorem: function non-injectivity

A function from a set of size at least k+1 to a set of size k is not one-to-one.

Proof. The k values are boxes; k+1 inputs are pigeons. ∎

Theorem: birthday collision approximation

For t random hashes into N=2^n values, probability of no collision is approximately exp(-t^2/(2N)). Setting this to 1/e gives t≈√(2N)=√2·2^{n/2}. Exam likely.

Proof. P_no = ∏_{i=0}^{t-1}(1-i/N) ≈ exp(-Σ i/N) ≈ exp(-t^2/(2N)). Set equal to 1/e. ∎

6. Worked examples

Example 1

Among 27 English words, two begin with the same letter (26 letters).

Example 2

To guarantee two students with the same score 0-100, need 102 students.

Example 3

In any 6 people, there are 3 mutual friends or 3 mutual strangers (Ramsey R(3,3)=6).

Example 4

Birthday paradox: with n-bit hash, about √2·2^{n/2} hashes give collision probability 1-1/e.

Example 5

Party problem: among at least 2 people, two know the same number of others (pigeonholes 0..n-1 with endpoints impossible).

9. Common mistakes and exam traps

  • Choosing the wrong pigeons/holes so the count inequality fails.
  • Using generalized form with wrong k.
  • Confusing 1/e non-collision with 1/2 collision probability.
  • Forgetting that pigeonhole gives existence, not construction.

10. Practice questions (assigned to this page)

Q16. Hash function to n bits; approximate number of hashes for 1/e chance of non-collision.

Solution: t≈√2·2^{n/2}. Python verification of formula structure: for n=10, t≈45.25.

11. Extra self-test questions

1. If 10 balls into 9 boxes, one box has at least?

2.

2. 100 objects into 10 boxes, one box has at least?

10.

3. Show among 5 points in an equilateral triangle of side 2, two are at distance less than 1.

Subdivide into 4 smaller equilateral triangles of side 1; pigeonhole gives two points in one small triangle, whose diameter is 1.

4. Words among 30 English words sharing first letter?

Yes, 30>26.

5. Birthday paradox threshold for 32-bit hash?

≈√2·2^16≈92682.

12. Cheat sheet

n+1 objects in n boxes ⇒ one box has ≥2.

nk+1 objects in n boxes ⇒ one box has ≥k+1.

n-1 objects in n boxes ⇒ one box empty.

Function from size k+1 to size k not injective.

Birthday: P_no≈exp(-t^2/(2N)), N=2^n.

1/e non-collision: t≈√(2N).
