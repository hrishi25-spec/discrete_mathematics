04 Inclusion-Exclusion

1. Why this topic matters

Many counting problems overcount elements that satisfy several conditions at once; inclusion-exclusion corrects this systematically. Derangements, surjections, Euler's totient, primes up to 200, bounded equations, and forbidden strings all reduce to one alternating sum over intersections. Once you can write the sets A_i, the formula does the rest.

2. Prerequisites

Basic counting (sum/product rules, combinations) from page 02; surjections and Stirling numbers from page 03; derangements are developed on this page.

3. Intuition

Counting "tea or coffee" by adding tea-lovers and coffee-lovers counts the both-tea-and-coffee people twice, so subtract their intersection. With three sets, subtracting all pairwise intersections removes the triple-overlap people three times and adds them back zero times, so add the triple intersection once. In general an element in exactly t sets is counted C(t,1)−C(t,2)+…+(−1)t+1C(t,t) = 1 times. The first picture shows the three-set overlap; the second shows the two-set correction with concrete numbers.

4. Definitions

Union/intersection: For finite sets A_i, |union A_i| counts elements in at least one set.

Surjection: a function X→Y that is onto; number Sur(n,k).

Derangement: a permutation with no fixed point; number D_n.

Euler totient φ(n): count of 1≤a≤n with gcd(a,n)=1.

5. Theorems and proofs

Every formula here is proved from the definition of a set union and the product rule; the proofs below are the full step-by-step versions used in exams.

Theorem IE-2 (two sets)

|A ∪ B| = |A| + |B| − |A ∩ B|. Exam likely.

  1. Split the union into disjoint pieces. A∪B is the disjoint union of A\B, A∩B and B\A, so |A∪B| = |A\B| + |A∩B| + |B\A|.
  2. Rewrite the two differences. A is the disjoint union of A\B and A∩B, hence |A\B| = |A|−|A∩B|; similarly |B\A| = |B|−|A∩B|.
  3. Substitute and simplify. |A∪B| = (|A|−|A∩B|) + |A∩B| + (|B|−|A∩B|) = |A|+|B|−|A∩B|. ∎

Theorem IE (general form)

For finite sets A1,…,Am,

|∪i=1m Ai| = Σi |Ai| − Σi<j |Ai∩Aj| + … + (−1)m−1 |∩i=1m Ai|. Exam likely.

Proof A (counting each element).

  1. Fix an element x in the union and let t ≥ 1 be the number of sets Ai containing it.
  2. Count how many terms of level r contain x. Choosing r of the t sets that contain x gives C(t,r) intersections; choosing any set that misses x contributes nothing. So the level-r sum contributes C(t,r) copies of x, with sign (−1)r+1.
  3. Add the contributions. The total coefficient of x is Σr=1t (−1)r+1 C(t,r).
  4. Evaluate by the binomial theorem. Σr=0t (−1)rC(t,r) = (1−1)t = 0, so Σr=1t (−1)r+1C(t,r) = 1 − (1−1)t = 1.
  5. Conclude. Every element of the union is counted exactly once, and an element outside every Ai is counted zero times. ∎

Proof B (induction on m, as in the lecture).

  1. Base case m=2: Theorem IE-2 gives |A∪B| = |A|+|B|−|A∩B|.
  2. Inductive hypothesis: assume the formula for m sets, writing the right side as Σ∅≠J⊆{1,…,m} (−1)|J|−1|∩i∈JAi|.
  3. Apply IE-2 to the union of the first m sets and Am+1: |∪i≤m+1Ai| = |∪i≤mAi| + |Am+1| − |(∪i≤mAi) ∩ Am+1|.
  4. Distribute the last intersection. (∪i≤mAi) ∩ Am+1 = ∪i≤m(Ai∩Am+1); apply the inductive hypothesis to the m sets Ai∩Am+1.
  5. Collect terms. The subsets J not containing m+1 keep their old sign; those containing m+1 arise with sign −(−1)(|J|−1)−1 = (−1)|J|−1. This is exactly the formula for m+1 sets. ∎

Theorem: surjections

Sur(n,k) = Σi=0k (−1)i C(k,i)(k−i)n = k!·S(n,k). Exam likely.

  1. Count all functions. A map X→Y with |X|=n, |Y|=k is built by giving each of the n elements one of k values, so there are kn.
  2. Define the bad sets. Let Ay be the functions that never take the value y. A function is not onto exactly when it lies in ∪y∈YAy.
  3. Count an intersection. For a fixed set I of i values forbidden from the image, the functions avoiding all of them are the maps into the remaining k−i values, so there are (k−i)n; there are C(k,i) such sets I.
  4. Apply IE. |∪yAy| = Σi=1k (−1)i+1 C(k,i)(k−i)n, and subtracting this from kn gives Σi=0k (−1)iC(k,i)(k−i)n.
  5. Relate to Stirling numbers. S(n,k) counts partitions into k unlabeled blocks; labelling the blocks in k! ways gives Sur(n,k) = k!·S(n,k). ∎

Theorem: derangements

Dn = n! Σi=0n (−1)i/i! = n! − C(n,1)(n−1)! + C(n,2)(n−2)! − … + (−1)n. Exam likely.

  1. Model as permutations. Put letter i into envelope i; there are n! permutations, and a derangement fixes no letter.
  2. Define the bad sets. Ai is the set of permutations fixing letter i. A derangement lies in none of the Ai.
  3. Count intersections. Fixing a specified set of i letters leaves (n−i)! permutations of the rest; there are C(n,i) such sets.
  4. Apply IE and subtract. Dn = n! − Σi=1n (−1)i+1C(n,i)(n−i)! = Σi=0n (−1)iC(n,i)(n−i)!.
  5. Simplify. Since C(n,i)(n−i)! = n!/i!, factor out n! to get n! Σi=0n (−1)i/i!. ∎

Theorem: Euler totient

φ(n) = n ∏p|n (1−1/p), product over distinct prime divisors p of n. Exam likely.

  1. Define the bad sets. For each prime divisor p of n, let Ap = {a : 1≤a≤n, p|a}. Then gcd(a,n)=1 exactly when a lies in none of these sets.
  2. Count intersections. The numbers divisible by distinct primes p1,…,pr are those divisible by their product, so |Ap1∩…∩Apr| = n/(p1…pr).
  3. Apply IE. φ(n) = n − Σp|n n/p + Σp<q n/(pq) − …
  4. Factor. This alternating sum is the expansion of n∏p|n(1−1/p), one factor for each distinct prime, so the two are equal. ∎

Theorem: bounded integer equations

For x1+…+xk=N with lower bounds xi≥ai and upper bounds xi≤bi, shift the lower bounds, then remove upper-bound violations by IE.

  1. Shift. Put yi = xi−ai≥0, so Σyi = N′ = N−Σai, with 0≤yi≤bi−ai. If N′<0 the answer is 0.
  2. Ignore upper bounds. By stars and bars there are C(N′+k−1,k−1) nonnegative solutions.
  3. Define bad sets. Bi is the set of solutions with yi≥ci+1, where ci = bi−ai. Subtracting ci+1 from that variable leaves C(N′−(ci+1)+k−1,k−1) solutions.
  4. Apply IE. Subtract single violations, add back pairwise violations, and so on; the alternating sum is the answer. ∎

6. Worked examples

Example 1 (easy): two sets

If |A|=40, |B|=35, |A∩B|=12, then by Theorem IE-2: |A∪B| = |A|+|B|−|A∩B| = 40+35−12 = 63. Equivalently, A only has 40−12=28 elements, B only has 35−12=23, and 28+12+23=63 — the same answer, shown in the second picture in section 3.

Example 2 (easy): a derangement of 4 objects

Use Theorem (derangements) with n=4: D4 = 4! − C(4,1)·3! + C(4,2)·2! − C(4,3)·1! + C(4,4)·0! = 24 − 24 + 12 − 4 + 1 = 9. Cross-check with the factorial form: 4!(1−1+1/2−1/6+1/24) = 24·(9/24) = 9. The probability is 9/24 = 3/8 = 0.375 (Q8).

Example 3 (medium): surjections from 5 elements to 4

By the surjection theorem with n=5, k=4: Sur(5,4) = Σi=04 (−1)iC(4,i)(4−i)5 = 45 − 4·35 + 6·25 − 4·15 = 1024 − 972 + 192 − 4 = 240. Cross-check: S(5,4)=10, so 4!·10 = 240 (Q7 on page 03).

Example 4 (medium–hard): a bounded equation

Solve x1+…+x4=20 with 1≤x1≤6, 0≤x2≤7, 4≤x3≤8, 2≤x4≤6 (Q23). Shift lower bounds: y1=x1−1∈[0,5], y2=x2∈[0,7], y3=x3−4∈[0,4], y4=x4−2∈[0,4], and Σyi=13.

Ignore upper bounds: C(13+4−1,3) = C(16,3) = 560. Subtract single violations: y1≥6 → C(10,3)=120; y2≥8 → C(8,3)=56; y3≥5 → C(11,3)=165; y4≥5 → C(11,3)=165; total 506. Add back pairwise violations: (6,8)→0, (6,5)→C(5,3)=10, (6,5)→10, (8,5)→C(3,3)=1, (8,5)→1, (5,5)→C(6,3)=20; total 42. All triples need more than 13, so they contribute 0. By IE: 560 − 506 + 42 = 96.

Example 5 (medium–hard): the elevator problem

Eight distinct people get off on floors 1–5 and the lift must be empty after floor 5, so every floor is used (Q19). Sur(8,5) = 58 − 5·48 + 10·38 − 10·28 + 5·18 = 390625 − 327680 + 65610 − 2560 + 5 = 126000.

Example 6 (hard): primes up to 200

Any composite ≤200 has a prime divisor among 2,3,5,7,11,13 (since 172>200). Count integers 1–200 divisible by at least one of these six primes by IE: Σ⌊200/p⌋ − Σ⌊200/(pq)⌋ + … = 159. Hence 200−159 = 41 integers are not divisible by any of them, and one of them is 1; the remaining 40 lie in [2,200] and are exactly the primes greater than 13. Adding the six small primes gives 40+6 = 46 primes ≤200 (Q27).

Example 7 (hard): forbidden strings

Count permutations of the 26 distinct letters containing none of fish, rat, bird (Q28). Treat each forbidden word as one block: fish gives 26−4+1=23 items → 23!; rat gives 24!; bird gives 23!. Intersections: fish and rat share no letters, so both blocks give 26−4−3+2=21 items → 21!. Fish and bird share i, and rat and bird share r, so those intersections are empty, as is the triple. IE: 26! − (23!+24!+23!) + 21! = 26! − 2·23! − 24! + 21! = 402619359782336797900800000.

9. Common mistakes and exam traps

  1. Forgetting to add back the triple intersection. Wrong: with |A|=40, |B|=35, |C|=30 and pairwise intersections 12, 8, 7, one gets 40+35+30−12−8−7 = 78. Right: add |A∩B∩C|=3, giving 81.
  2. Treating a strict inequality as non-strict (Q9). Wrong: for x1+…+x5<25 with xi≥1, using sum ≤25 gives C(25,5) = 53130. Right: "<25" means sum ≤24, and after shifting yi=xi−1 the count is C(24,5) = 42504.
  3. Treating forbidden words that share letters as independent blocks (Q28). Wrong: adding back an intersection for fish and bird, which share i, as if both could occur. Right: that intersection is impossible; only fish and rat (disjoint letters) can both occur, giving 26! − 2·23! − 24! + 21!.
  4. Using the large-n limit for a small derangement probability. Wrong: for four students, probability = 1/e ≈ 0.3679. Right: D4/4! = 9/24 = 0.375; 1/e is only the limit.
  5. Repeating a prime in the Euler product. Wrong: φ(12) = 12(1−1/2)(1−1/2)(1−1/3) = 2. Right: one factor per distinct prime, φ(12) = 12(1−1/2)(1−1/3) = 4.
  6. Stopping at the sieve count for primes ≤200. Wrong: the 40 integers left after sieving by 2,3,5,7,11,13 are "the primes". Right: add the six sieve primes themselves, 40+6 = 46.
  7. Forgetting to add back pairwise violations in a bounded equation (Q23). Wrong: 560−506 = 54. Right: add back the 42 pairwise overlaps, 560−506+42 = 96.

10. Practice questions (assigned to this page)

Q8. Four students pick keys randomly; probability none opens their own room.

Step 1. Model the picking as a random permutation of the four keys: 4! = 24 equally likely assignments.

Step 2. "None opens their own room" means the permutation has no fixed point, i.e. it is a derangement. By the derangement theorem, D4 = 4!(1−1+1/2−1/6+1/24) = 24−24+12−4+1 = 9.

Step 3. Probability = 9/24 = 3/8 = 0.375.

Q9. (a) x1+…+x5 < 25, xᵢ ≥ 1. (b) same with x2 < 5.

(a) Step 1. Since the xi are integers, x1+…+x5 < 25 means the sum is at most 24. Put yi = xi−1 ≥ 0; then Σyi ≤ 19.

(a) Step 2. Add a slack variable y6 = 19−Σyi ≥ 0. The six nonnegative variables sum to 19, so by stars and bars the count is C(19+6−1,6−1) = C(24,5) = 42504.

(b) Step 1. Here the base equation has xi ≥ 0; add slack so six nonnegative variables sum to 24. Total = C(24+6−1,5) = C(29,5) = 118755.

(b) Step 2. Remove x2 ≥ 5: write x2′ = x2−5 ≥ 0, so the six variables now sum to 19, giving C(24,5) = 42504 bad solutions.

(b) Step 3. Subtract: 118755−42504 = 76251. A single exclusion suffices because only one upper restriction is present.

Q15. Musical chairs twice; probability of no winner.

Step 1. The players walk in unison, so one round is a cyclic shift of the chairs by one of 5 offsets, each equally likely. Offset 0 gives every player their own chair; the other 4 offsets give it to nobody.

Step 2. "No winner" means no player ever sits in their own chair, so both rounds must use a nonzero offset: probability (4/5)·(4/5) = 16/25 = 0.64.

Step 3. For n players the same argument gives (1−1/n)2, which tends to 1 as n→∞.

Second reading. If a round were a uniformly random permutation rather than a cyclic shift, the chance that nobody gets their own chair in both rounds would be (D5/5!)2 = (44/120)2 = 121/900 ≈ 0.1344. The lecture's "walk in unison" wording fixes the cyclic-shift reading.

Q17. State and prove the Inclusion–Exclusion Principle.

Statement. For finite sets A1,…,Am, |∪iAi| = Σ∅≠J⊆{1,…,m} (−1)|J|−1 |∩i∈JAi|.

Proof, step 1. Fix an element x in the union and let t≥1 be the number of sets containing it.

Step 2. At level r, x occurs in C(t,r) of the intersections, each with sign (−1)r+1.

Step 3. Its total coefficient is Σr=1t (−1)r+1C(t,r) = 1−(1−1)t = 1, by the binomial theorem.

Step 4. Elements outside every Ai contribute 0, so the right side counts exactly the elements of the union. ∎ (An induction proof is given as Proof B in section 5.)

Q18. Prove φ(n) = n∏_{p|n}(1−1/p).

Step 1. For each prime divisor p of n, let Ap = {a : 1≤a≤n, p|a}. Then φ(n) counts the elements in none of these sets.

Step 2. For distinct primes p1,…,pr, the intersection Ap1∩…∩Apr has size n/(p1…pr).

Step 3. Inclusion–exclusion gives φ(n) = n − Σp|n n/p + Σp<q n/(pq) − …

Step 4. Expanding ∏p|n(1−1/p) gives exactly the same alternating sum, so φ(n) = n∏p|n(1−1/p). ∎

Q19. 8 people, elevator empties on the fifth floor; count ways.

Step 1. Floors 1–5 must all be used, so each of the 8 distinct people chooses a floor and every floor receives at least one person: this is a surjection from an 8-set to a 5-set.

Step 2. Sur(8,5) = Σi=05 (−1)iC(5,i)(5−i)8 = 58 − 5·48 + 10·38 − 10·28 + 5·18.

Step 3. = 390625 − 327680 + 65610 − 2560 + 5 = 126000. (Cross-check: 5!·S(8,5) = 120·1050 = 126000.)

Q23. x1+…+x4 = 20 with 1≤x1≤6, 0≤x2≤7, 4≤x3≤8, 2≤x4≤6.

Full working is in example 4. Shift lower bounds to get Σyi=13 with caps (5,7,4,4). Unrestricted count C(16,3)=560; subtract singles 120+56+165+165=506; add pairs 0+10+10+1+1+20=42; triples and the quadruple are impossible.

Answer: 560−506+42 = 96.

Q24. Reseat n people so that everyone has a different right neighbour.

Step 1. Fix the original circular order (1,2,…,n). For each person i, forbid the event that i+1 (mod n) is their right neighbour again.

Step 2. Glue a forbidden successive pair into a block. Choosing k disjoint forbidden pairs can be done in (1/(n−k))C(n−k,k)·n ways on a circle, which simplifies to the count below; applying inclusion–exclusion over all forbidden neighbours gives

Σk=0n−1 (−1)k C(n,k)(n−k−1)! + (−1)n.

Step 3. For n=5: 4! − 5·3! + 10·2! − 10·1! + 5·0! − 1 = 24−30+20−10+5−1 = 8. A brute-force enumeration of circular arrangements of 5 people gives 8, confirming the formula.

Q27. Number of primes ≤200.

Step 1. Every composite ≤200 has a prime factor among 2,3,5,7,11,13, because 172=289>200.

Step 2. Sieve integers 1–200 by these six primes with inclusion–exclusion: 159 are divisible by at least one of them, leaving 200−159 = 41.

Step 3. Of those 41, the number 1 is not prime; the other 40 are primes above 13. Adding the six sieve primes gives 40+6 = 46 primes ≤200.

Q28. Permutations of 26 letters containing none of fish, rat, bird.

Step 1. Treat each word as a block: fish (4 letters) gives 26−4+1 = 23 items → 23!; rat (3 letters) gives 24!; bird (4 letters) gives 23!.

Step 2. Intersections: fish and rat share no letters, so both blocks fit as 26−4−3+2 = 21 items → 21!. Fish and bird share i; rat and bird share r; those intersections (and the triple) are empty.

Step 3. Inclusion–exclusion: 26! − (23!+24!+23!) + 21! = 26! − 2·23! − 24! + 21! = 402619359782336797900800000.

11. Extra self-test questions

1. How many integers 1–100 are divisible by 2, 3 or 5?

Let A, B, C be divisibility by 2, 3, 5. |A|=50, |B|=33, |C|=20; pairwise intersections are divisibility by 6, 10, 15 with sizes 16, 10, 6; the triple is divisibility by 30 with size 3. By IE: 50+33+20−16−10−6+3 = 74.

2. How many onto functions from a 6-set to a 3-set?

Sur(6,3) = 36 − 3·26 + 3·16 = 729 − 192 + 3 = 540.

3. What is D5?

D5 = 5!(1−1+1/2−1/6+1/24−1/120) = 120·(11/30) = 44. Equivalently 120−120+60−20+5−1 = 44.

4. What is φ(12)?

The distinct prime divisors are 2 and 3, so φ(12) = 12(1−1/2)(1−1/3) = 12·1/2·2/3 = 4 (namely 1, 5, 7, 11).

5. Solutions of x1+x2+x3=10 with 0≤xᵢ≤4?

Unrestricted: C(12,2)=66. Subtract each violation xi≥5: shift by 5 leaves sum 5, giving C(7,2)=21 each, 63 in total. Add back pairs: two variables shifted by 5 leave sum 0, giving C(2,2)=1 per pair, 3 pairs. Triples are impossible. Answer 66−63+3 = 6.

6. What is D6?

D6 = 6!(1−1+1/2−1/6+1/24−1/120+1/720) = 720 − 720 + 360 − 120 + 30 − 6 + 1 = 265.

7. What is φ(30)?

30 = 2·3·5, so φ(30) = 30(1−1/2)(1−1/3)(1−1/5) = 30·1/2·2/3·4/5 = 8.

8. How many surjections from a 5-set to a 3-set?

Sur(5,3) = 35 − 3·25 + 3·15 = 243 − 96 + 3 = 150.

12. Cheat sheet

Definitions

  • Union/intersection: |∪iAi| counts elements in at least one set; ∩ means in every set.
  • Surjection Sur(n,k): onto functions from an n-set to a k-set.
  • Derangement Dn: a permutation with no fixed point.
  • Euler totient φ(n): integers 1≤a≤n with gcd(a,n)=1.

Formulas

  • Two sets: |A∪B| = |A|+|B|−|A∩B|.
  • Three sets: |A∪B∪C| = |A|+|B|+|C| − |A∩B|−|A∩C|−|B∩C| + |A∩B∩C|.
  • General: |∪i=1mAi| = Σ∅≠J⊆{1,…,m} (−1)|J|−1|∩i∈JAi|; signs alternate + − + −.
  • Why it works: an element in t sets is counted Σr=1t (−1)r+1C(t,r) = 1−(1−1)t = 1 times.
  • Surjections: Sur(n,k) = Σi=0k (−1)iC(k,i)(k−i)n = k!·S(n,k).
  • Derangements: Dn = n! Σi=0n (−1)i/i!; probability ≈ 1/e for large n.
  • Euler totient: φ(n) = n∏p|n(1−1/p), one factor per distinct prime.
  • Bounded equations: shift lower bounds, count by stars and bars, then remove upper-bound violations by IE.
  • Forbidden words: block each word; an intersection exists only when the words share no letters.
  • Primes ≤N: sieve by primes ≤√N, then add those small primes back.

Exam checklist

  1. Define the bad sets Ai precisely before writing any sum.
  2. Alternate signs: add singles, subtract pairs, add triples.
  3. Count intersections with stars and bars, factorials, or floor functions, as appropriate.
  4. Check whether overlapping "bad words" can occur together at all.
  5. For primes, sieve by primes up to √N and add those primes back.
  6. For inequalities, check strict versus non-strict before shifting variables.
