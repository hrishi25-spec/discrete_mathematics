10 Logic, Proof Techniques, Induction

1. Why this topic matters

Every theorem in this course is built from definitions and proof techniques. The exam tests whether you can choose the right proof method (direct, contrapositive, contradiction, induction) and avoid invalid induction. The quantifier and induction typos in the slides are classic traps, so they are corrected here.

2. Prerequisites

Set and relation definitions from page 01.

3. Intuition

Logic is the grammar of proofs. A proof is a chain from axioms and definitions to the conclusion, with every link valid. The first picture shows the induction ladder: prove the base rung, then show each rung lifts you to the next. The second picture shows the truth table for implication, whose single false row explains why contraposition works: P⇒Q and ¬Q⇒¬P are false in exactly the same situation.

4. Definitions

Proposition: statement that is true or false.

Axiom: statement assumed true.

Theorem/lemma/corollary: proven statements.

Implication P⇒Q: false only when P true and Q false.

Contrapositive: ¬Q⇒¬P, equivalent to P⇒Q.

Converse: Q⇒P; inverse: ¬P⇒¬Q (not equivalent in general).

Quantifiers: ∀x P(x), ∃x P(x). Correct translation of "if P(x) then Q(x)" is ∀x(P(x)⇒Q(x)), not biconditional.

Logical operators on two variables: 2^4=16, since four truth assignments each have two possible outputs.

Tautology / contradiction / contingency: always true, always false, or neither, respectively.

Logical equivalence: P≡Q when P⇔Q is a tautology; equivalent statements have identical truth tables.

Useful identities: P⇒Q ≡ ¬P∨Q, and ¬(P⇒Q) ≡ P∧¬Q.

5. Theorems and complete proofs

Theorem: Principle of Mathematical Induction (PMI)

If P(1) is true and for all k≥1, P(k)⇒P(k+1), then P(n) is true for all n≥1. Exam likely.

  1. Assume a counterexample exists. Let S = {n≥1 : P(n) is false} and suppose S is nonempty.
  2. Choose the least one. By well-ordering of the positive integers, S has a least element m.
  3. It is not the base case. P(1) is true, so m≠1 and therefore m≥2.
  4. The predecessor is good. By minimality, m−1∉S, so P(m−1) is true.
  5. Apply the step. With k=m−1≥1, the inductive implication gives P(m), contradicting m∈S.
  6. Conclusion. S is empty, so P(n) holds for every n≥1. ∎

Theorem: Strong induction

If P(1) is true and for all k>1, (∀1≤t<k, P(t))⇒P(k), then P(n) is true for all n≥1.

  1. Assume a counterexample exists. Let S be the set of n with P(n) false, and suppose S is nonempty with least element m.
  2. Rule out the base. P(1) is true, so m>1.
  3. All smaller cases hold. For every 1≤t<m, minimality gives t∉S, so P(t) is true.
  4. Apply the strong step. The hypothesis with k=m yields P(m), contradicting m∈S. ∎

Theorem: De Morgan for quantifiers

¬∀x P(x) ≡ ∃x ¬P(x); ¬∃x P(x) ≡ ∀x ¬P(x).

  1. First equivalence, forward. If ¬∀x P(x) is true, not every object satisfies P, so some object fails P: ∃x ¬P(x) is true.
  2. First equivalence, backward. If ∃x ¬P(x) is true, an object failing P shows that not every object satisfies P.
  3. Second equivalence. ¬∃x P(x) is true exactly when no object satisfies P, i.e. every object fails P: ∀x ¬P(x). ∎

Theorem: converse and inverse

For P⇒Q, the converse Q⇒P and the inverse ¬P⇒¬Q are equivalent to each other but not to the original implication.

  1. Converse false row. Q⇒P is false exactly when Q is true and P is false.
  2. Inverse false row. ¬P⇒¬Q is false when ¬P is true and ¬Q is false, again P false and Q true. Hence converse ≡ inverse.
  3. Different from the original. P⇒Q is false on the row P true, Q false, which is not the row above.
  4. Concrete counterexample. Let P be "n divisible by 4" and Q be "n even". P⇒Q is true, but at n=6 the converse "n even ⇒ n divisible by 4" is false. ∎

Theorem: contrapositive equivalence

P⇒Q ≡ ¬Q⇒¬P.

  1. Locate the false row. P⇒Q is false exactly when P is true and Q is false (the second row of the truth table in section 3).
  2. Analyse the contrapositive. ¬Q⇒¬P is false exactly when ¬Q is true and ¬P is false, i.e. Q false and P true.
  3. Compare. Both are false on precisely the same row and true on all others, so they are logically equivalent. ∎

6. Worked examples

Example 1 (direct proof): odd n gives odd n2

Step 1. Assume n is odd, so n=2k+1 for an integer k.

Step 2. Expand: n2 = 4k2+4k+1 = 2(2k2+2k)+1.

Step 3. This has the form 2m+1 with m=2k2+2k, hence n2 is odd. ✔

Example 2 (contrapositive): 3n+2 odd implies n odd

Step 1. The contrapositive is: if n is even, then 3n+2 is even.

Step 2. Write n=2k; then 3n+2 = 6k+2 = 2(3k+1), which is even.

Step 3. The contrapositive is equivalent to the original, so the claim holds.

Example 3 (induction): the sum of the first n integers

Base. For n=1, 1 = 1·2/2.

Step. Assume 1+…+k = k(k+1)/2. Then 1+…+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k/2+1) = (k+1)(k+2)/2.

Check. At n=10 the formula gives 10·11/2 = 55 = 1+…+10. ✔

Example 4 (induction): geometric sum

Claim. 1+2+22+…+2n = 2n+1−1.

Base. n=0: 1 = 21−1.

Step. If the sum up to 2k equals 2k+1−1, adding 2k+1 gives 2·2k+1−1 = 2k+2−1.

Check. n=4: 1+2+4+8+16 = 31 = 25−1. ✔

Example 5 (contradiction): √2 is irrational

Step 1. Suppose √2 = a/b with integers a,b, b≠0 and gcd(a,b)=1.

Step 2. Squaring gives 2 = a2/b2, so a2 = 2b2; hence a2 is even and a is even.

Step 3. Write a=2k. Then 4k2 = 2b2, so b2 = 2k2 and b is even too.

Step 4. Both a and b are even, contradicting gcd(a,b)=1. Therefore √2 is irrational.

Example 6 (counterexamples): two false claims

"Every positive integer is a sum of two squares" fails at 3: the squares below 3 are 0 and 1, and 1+1=2, 1+4=5, so 3 is impossible. The claim "n2+n+41 is always prime" fails at n=40: 402+40+41 = 1681 = 412. A single counterexample disproves a universal statement.

Example 7 (vacuous and trivial implications)

For "if n>1 then n2>n", the case n=0 has a false antecedent, so the implication is vacuously true; n>1 is proved directly. For "if a≥b≥0 then an≥bn", the case a=b=0 makes the conclusion trivially true.

Example 8 (computation): trailing zeroes of 1000!

Zeroes come from factors of 10=2·5, and factors of 5 are scarcer. Count them with floors: ⌊1000/5⌋ = 200, ⌊1000/25⌋ = 40, ⌊1000/125⌋ = 8, ⌊1000/625⌋ = 1, and 55>1000. Total = 200+40+8+1 = 249.

Example 9 (constructive existence): 1729

To prove that some positive integer is a sum of two positive cubes in two ways, exhibit one: 103+93 = 1000+729 = 1729 and 123+13 = 1728+1 = 1729. This is a constructive existence proof.

Example 10 (backward reasoning): AM–GM

For a,b≥0, work backwards: (a+b)/2 ≥ √ab ⇔ a+b ≥ 2√ab ⇔ (a+b)2 ≥ 4ab ⇔ (a−b)2 ≥ 0. The last statement is always true, and every step is reversible because both sides are nonnegative.

Example 11 (invalid induction): all Fibonacci numbers even

The faulty proof checks only F0=0 as base, then assumes F0,…,Fn−1 even to prove Fn = Fn−1+Fn−2 even. For n=2 the hypothesis would require F1 even, but F1=1 is odd. A second-order recurrence needs two base cases; the claim is false.

Example 12 (valid induction): Fibonacci matrix

Claim. [[1,1],[1,0]]n = [[Fn+1,Fn],[Fn,Fn−1]].

Base. n=1 gives [[1,1],[1,0]] = [[F2,F1],[F1,F0]].

Step. Multiply the n-th matrix on the right by [[1,1],[1,0]]; the entries become Fn+1+Fn = Fn+2 and Fn+Fn−1 = Fn+1.

Check. n=4 gives [[5,3],[3,2]], matching (F5,F4,F3) = (5,3,2). ✔

9. Common mistakes and exam traps

  1. Using the converse instead of the contrapositive. Wrong: to prove "if n is divisible by 4 then n is even", prove "if n is even then it is divisible by 4" — false at n=6. Right: prove the contrapositive "if n is odd then it is not divisible by 4".
  2. Missing the base case. Wrong: show only that the formula 1+…+n=n(n+1)/2 is preserved by adding n+1. Right: also check n=1, where 1=1·2/2.
  3. Applying the induction step where it fails. Wrong: in the all-pigeons-same-colour argument, use the overlap for k=2. Right: the two remaining one-pigeon sets do not overlap; the step works only from k≥3, so the base cases must cover that gap.
  4. Checking finitely many cases. Wrong: verify n2+n+41 is prime for n=1,…,10 and declare it always prime. Right: at n=40 the value is 1681 = 412, so the universal claim is false.
  5. Using a biconditional for an implication. Wrong: translate "every person 21 or older is eligible" as ∀x(P(x)⇔Q(x)). Right: ∀x(P(x)⇒Q(x)); the biconditional incorrectly also says eligibility requires being 21+.
  6. Ignoring the domain of AM–GM. Wrong: apply (a+b)/2≥√ab to distinct reals such as a=−4, b=−1, giving −2.5≥2. Right: the inequality requires a,b≥0, and then it follows from (a−b)2≥0.
  7. Using one base case for a second-order recurrence. Wrong: prove "all Fibonacci numbers are even" from the base F0=0 alone. Right: a recurrence of order two needs F0 and F1; F1=1 is odd, so the claim is false.
Slide errors I fixed: PMI was written as "for all k>1" (should be k≥1); strong induction was written with 1<t<k (should be 1≤t<k); AM-GM was stated for "distinct reals" (requires a,b≥0); quantifier slide uses a biconditional where an implication is meant.

11. Extra self-test questions

1. Is √2 irrational? Prove by contradiction.

Yes. Suppose √2=a/b in lowest terms. Then a2=2b2, so a is even; write a=2k. Then b2=2k2, so b is even too. Both even contradicts gcd(a,b)=1.

2. Prove 1+2+…+n = n(n+1)/2 by induction.

Base n=1: 1=1·2/2. Step: assume 1+…+k=k(k+1)/2; then adding k+1 gives (k+1)(k+2)/2. Check n=10: 55=10·11/2. ✔

3. "If n is even then n2 is even" is the contrapositive of what?

It is the contrapositive of "if n2 is odd then n is odd": with P="n even" and Q="n² even", ¬Q is "n² odd" and ¬P is "n odd".

4. Correct quantifier form of "every person 21 or older is eligible"?

Let P(x) be "21 or older" and Q(x) "eligible". The sentence says only that P is sufficient, so ∀x(P(x)⇒Q(x)). The biconditional ∀x(P(x)⇔Q(x)) would wrongly add the reverse direction.

5. Why is the all-pigeons-same-colour induction invalid?

The step needs two overlapping (k−1)-subsets, which requires k≥3. At k=2 the two one-pigeon remainders do not overlap, so the step fails; the base case only covers k=1, leaving a gap.

6. Prove 1+2+22+…+2n = 2n+1−1.

Base n=0: 1=2−1. Step: if the sum through 2k is 2k+1−1, adding 2k+1 gives 2k+2−1. Check n=4: 1+2+4+8+16=31=25−1. ✔

7. Verify the Fibonacci matrix identity at n=4.

Multiply [[1,1],[1,0]] four times to get [[5,3],[3,2]]. The formula predicts [[F5,F4],[F4,F3]] = [[5,3],[3,2]], since F3=2, F4=3, F5=5. They agree.

8. How many logical operators on two variables?

Two variables have 22=4 truth assignments; each operator chooses T or F on each assignment, so there are 24=16 operators. These include AND, OR, implication, XOR and the two constants.

12. Cheat sheet

Definitions

  • Proposition: sentence that is true or false; axiom: assumed true.
  • Formal proof: a chain of valid deductions from axioms and proved statements.
  • Tautology / contradiction / contingency: always true / always false / neither.
  • Logical equivalence: P≡Q iff P⇔Q is a tautology (same truth table).
  • Quantifiers: ∀x P(x), ∃x P(x); ¬∀x P ≡ ∃x ¬P and ¬∃x P ≡ ∀x ¬P.

Implication identities

  • P⇒Q is false only when P=T and Q=F.
  • P⇒Q ≡ ¬Q⇒¬P (contrapositive) ≡ ¬P∨Q.
  • ¬(P⇒Q) ≡ P∧¬Q.
  • Converse Q⇒P ≡ inverse ¬P⇒¬Q, but neither is equivalent to P⇒Q.
  • P⇔Q ≡ (P⇒Q)∧(Q⇒P).
  • There are 24=16 operators on two variables.

Proof methods

  • Direct: assume P, deduce Q. Contrapositive: prove ¬Q⇒¬P.
  • Contradiction: assume ¬P, derive R∧¬R. Counterexample: one case disproves ∀.
  • Cases: exhaustive, preferably disjoint. Computation: finite check.
  • Existential: construct an example. Backward reasoning: find true Q with Q⇒P.
  • PMI: prove P(1), then P(k)⇒P(k+1) for k≥1.
  • Strong induction: from P(1) and (∀1≤t<k P(t))⇒P(k) prove P(k).
  • Check that the induction step works for its smallest case; order-r recurrences need r base cases.

Exam checklist

  1. Name P and Q explicitly before choosing a method.
  2. Use the contrapositive, never the converse, to prove P⇒Q.
  3. Write the base case and verify the step for the smallest applicable index.
  4. State domain restrictions, e.g. a,b≥0 for AM–GM.
  5. Give one explicit counterexample to disprove a universal claim.
