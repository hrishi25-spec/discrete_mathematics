10 Logic, Proof Techniques, Induction

1. Why this topic matters

Every theorem in this course is built from definitions and proof techniques. The exam tests whether you can choose the right proof method (direct, contrapositive, contradiction, induction) and avoid invalid induction. The quantifier and induction typos in the slides are classic traps, so they are corrected here.

Set and relation definitions from page 01.

3. Intuition

Logic is the grammar of proofs. A proof is a chain from axioms/definitions to the conclusion. Induction is like a ladder: prove the first rung, then show each rung implies the next. The picture below shows the induction ladder.

4. Definitions

Proposition: statement that is true or false.

Axiom: statement assumed true.

Theorem/lemma/corollary: proven statements.

Implication P⇒Q: false only when P true and Q false.

Contrapositive: ¬Q⇒¬P, equivalent to P⇒Q.

Converse: Q⇒P; inverse: ¬P⇒¬Q (not equivalent in general).

Quantifiers: ∀x P(x), ∃x P(x). Correct translation of "if P(x) then Q(x)" is ∀x(P(x)⇒Q(x)), not biconditional.

Logical operators on two variables: 2^4=16, since four truth assignments each have two possible outputs.

5. Theorems and complete proofs

Theorem: Principle of Mathematical Induction (PMI)

If P(1) is true and for all k≥1, P(k)⇒P(k+1), then P(n) is true for all n≥1. Exam likely.

Proof. Let S be the set of n for which P(n) is true. Base gives 1∈S. Inductive step says S is closed upward from 1. By well-ordering of positive integers, S contains all positive integers. ∎

Theorem: Strong induction

If P(1) is true and for all k>1, (∀1≤t<k, P(t))⇒P(k), then P(n) is true for all n≥1.

Proof. Same well-ordering argument, using all previous cases. ∎

Theorem: De Morgan for quantifiers

¬∀x P(x) ≡ ∃x ¬P(x); ¬∃x P(x) ≡ ∀x ¬P(x).

Proof. Directly from meanings of "for all" and "there exists." ∎

Converse and inverse (not equivalent in general)

For P⇒Q, converse is Q⇒P and inverse is ¬P⇒¬Q; they are equivalent to each other but not to P⇒Q. See the slide truth table.

Theorem: contrapositive equivalence

P⇒Q ≡ ¬Q⇒¬P.

Proof. Truth tables: both are false exactly when P true and Q false. ∎

6. Worked examples

Example 1: direct proof

If n is odd, n^2 is odd: n=2k+1 ⇒ n^2=4k^2+4k+1=2(2k^2+2k)+1.

Example 2: contrapositive

If 3n+2 is odd then n is odd. Contrapositive: if n even then 3n+2 even. n=2k ⇒ 3n+2=6k+2=2(3k+1).

Example 3: induction

1+...+n=n(n+1)/2. Base n=1. If true for k, then sum to k+1 = k(k+1)/2 + (k+1) = (k+1)(k+2)/2.

Example 4: contradiction

√2 is irrational: assume a/b in lowest terms; then a,b both even, contradiction.

Example: Fibonacci all-even fallacy

The claim "all Fibonacci numbers are even" fails because F_1=1 is odd; the induction hypothesis for n=2 incorrectly assumes F_1 even.

Example: AM-GM backward reasoning

For a,b≥0, (a+b)/2≥√ab follows by squaring to (a-b)^2≥0.

Example: matrix-Fibonacci induction

Induction proves [[1,1],[1,0]]^n = [[F_{n+1},F_n],[F_n,F_{n-1}]].

Example: 1000! trailing zeros

Count factors of 5: floor(1000/5)+floor(1000/25)+floor(1000/125)+floor(1000/625)=249.

Example: 1729

1729=10^3+9^3=12^3+1^3 gives a constructive existence proof.

Example 5: counterexample

"Every positive integer is sum of two squares" is false: 3 cannot be so expressed.

9. Common mistakes and exam traps

  • Using converse instead of contrapositive.
  • Missing base case in induction.
  • Induction step failing for smallest case (all pigeons same color fallacy).
  • Proving only finitely many cases and claiming general truth.
  • Using biconditional when only implication is meant (quantifier slide).
Slide errors I fixed: PMI was written as "for all k>1" (should be k≥1); strong induction was written with 1<t<k (should be 1≤t<k); AM-GM was stated for "distinct reals" (requires a,b≥0); quantifier slide uses a biconditional where an implication is meant.

11. Extra self-test questions

1. Is sqrt(2) irrational? Prove by contradiction.

Yes; standard proof as above.

2. Prove 1+2+...+n=n(n+1)/2 by induction.

Base and step as above.

3. Is "if n even then n^2 even" proved by contrapositive of what?

Contrapositive of "if n^2 odd then n odd".

4. Correct quantifier translation of "Every person who is 21+ is eligible"?

∀x (P(x)⇒Q(x)).

5. Why is the all-pigeons-same-color induction invalid?

Induction step fails for k=2 (no overlapping pigeon).

12. Cheat sheet

P⇒Q false only P true, Q false.

Contrapositive ¬Q⇒¬P is equivalent.

Converse/inverse are not equivalent generally.

De Morgan for quantifiers swaps ∀/∃ and negates.

PMI: base + inductive step.

Strong induction: use all previous cases.

Induction step must work for smallest case.
