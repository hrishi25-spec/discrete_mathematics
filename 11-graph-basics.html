11 Graph Basics

1. Why this topic matters

Graphs model relationships: bridges, networks, schedules, assignments. The basics (definitions, walks/paths, components, degree, isomorphism, Petersen graph) support every later graph topic. Exam questions often test definitions precisely and ask for short proofs like handshaking or connectivity.

2. Prerequisites

Set theory and counting from page 01 and page 02.

3. Intuition

A graph is a set of vertices plus edges connecting them. A walk can repeat vertices and edges; a trail cannot repeat edges; a path cannot repeat vertices. Components are the connected pieces. The first picture is a path on four vertices; the second contrasts a walk that repeats with a path that does not.

4. Definitions

Graph: vertex set V, edge set E, endpoint assignment.

Simple graph: no loops or multiple edges.

Degree: number of incident edges (loop counts 2).

Walk/trail/path/cycle: walk allows repeats; trail no repeated edges; path no repeated vertices; cycle closed path.

Connected: every pair has a path.

Component: maximal connected subgraph.

Isomorphism: bijection preserving adjacency both ways.

5. Theorems and complete proofs

Each proof is written in numbered steps; the only fact quoted without proof here is the standard non-planarity of the Petersen graph.

Theorem: handshaking lemma

In any graph, the number of vertices of odd degree is even. Exam likely.

  1. Count edge-ends. Every edge has two endpoints, so Σv deg(v) = 2|E|, an even number (a loop contributes 2, as required).
  2. Split the sum. Separate vertices of even degree and odd degree: Σeven deg(v) + Σodd deg(v) = 2|E|.
  3. Reduce mod 2. The even-degree sum is even, so Σodd deg(v) is even.
  4. Conclude. A sum of odd numbers is even only if there is an even number of them. ∎

Theorem: components bound

A graph with n vertices and m edges has at least n−m components. Exam likely.

  1. Start empty. With n vertices and no edges, there are exactly n components.
  2. Add edges one at a time. An edge joins two vertices; if they lie in different components those two merge (count drops by 1), while an edge inside one component leaves the count unchanged.
  3. Bound the drop. Each of the m edges reduces the component count by at most 1, so the total drop is at most m.
  4. Conclude. The remaining number of components is at least n−m. ∎

Theorem: every walk contains a path

Every u,v-walk contains a u,v-path.

  1. Use induction on the walk length. A walk with no repeated vertex is already a path.
  2. Find a repeat. Otherwise there is a vertex x occurring at positions i<j.
  3. Delete the closed portion. Remove the steps from position i+1 to j; the remaining sequence is still a u,v-walk and is shorter, with the endpoint v unchanged.
  4. Repeat. Termination is guaranteed because the length strictly decreases; the result is a walk with no repeated vertex, i.e. a path. ∎

Theorem: connection is an equivalence relation

u~v iff there is a u,v-path is an equivalence relation; its classes are components.

  1. Reflexive: the length-0 walk from u to itself counts as a path.
  2. Symmetric: reverse a u,v-path to get a v,u-path.
  3. Transitive: concatenate a u,v-walk with a v,w-walk; by the previous theorem the resulting u,w-walk contains a path.
  4. Classes: the equivalence class of u is exactly the set of vertices reachable from u, which is the definition of its connected component. ∎

Theorem: connected graph edge minimum

A connected n-vertex graph has at least n−1 edges.

  1. Count components. A connected graph has exactly c=1 component.
  2. Apply the components bound. 1 ≥ n−m, so m ≥ n−1. ∎

Theorem: min degree connectivity

If a simple graph G has minimum degree δ ≥ (n−1)/2, then G is connected. Exam likely (Q38).

  1. Suppose G is disconnected. Let its components have sizes a1,…,ar with r≥2 and Σai=n.
  2. Bound degrees inside a component. A vertex in a component of size a has at most a−1 neighbours, so δ ≤ ai−1 for every i.
  3. Convert to a size bound. Hence each ai ≥ δ+1 ≥ (n+1)/2.
  4. Contradiction. Two components already give n ≥ a1+a2 ≥ n+1, impossible. So r=1. ∎

Theorem: graph or complement connected

For any simple graph G, either G or its complement is connected. Exam likely (Q39).

  1. If G is connected, done. Otherwise its components C1,…,Cr satisfy r≥2.
  2. Cross-component pairs. If u∈Ci and v∈Cj with i≠j, then uv∉E(G), so uv∈E(Ḡ).
  3. Within one component. For u,v∈Ci, choose w in another component; by step 2, uw and wv are complement edges, giving a complement path from u to v.
  4. Conclusion. Every pair of vertices is joined in the complement, so Ḡ is connected. ∎

Theorem: Petersen graph properties

The Petersen graph has 10 vertices, 15 edges, degree 3, girth 5, diameter 2, and is vertex-transitive and non-planar. Exam likely. Not in slides - standard result. (Non-planarity is quoted; the other claims are proved below.)

  1. Model it. Vertices are the 2-subsets of {1,2,3,4,5}; two are adjacent when the subsets are disjoint. There are C(5,2)=10 vertices.
  2. Degree and edges. A fixed pair {a,b} is disjoint from the C(3,2)=3 pairs from the remaining three elements, so the graph is 3-regular; handshaking gives 10·3/2 = 15 edges.
  3. No triangle. Three pairwise disjoint 2-subsets would need 6 distinct elements, but only 5 exist.
  4. No 4-cycle. Two non-adjacent vertices (pairs sharing one element) have exactly one common neighbour: the pair disjoint from their union. A 4-cycle would require two common neighbours, so girth ≥5; a 5-cycle exists (e.g. {1,2},{3,4},{1,5},{2,3},{4,5}), so girth is 5.
  5. Diameter 2. Adjacent pairs are at distance 1; non-adjacent pairs share exactly one neighbour as in step 4, so distance 2. ∎

Complements, cliques, and matrices

Complement: same vertices; uv is an edge iff it is not an edge in G.

Clique: pairwise adjacent vertices. Independent set: pairwise non-adjacent.

Adjacency matrix: A_{ij}=number of edges between v_i and v_j. Incidence matrix: M_{ij}=1 if v_i is endpoint of e_j.

Automorphisms of Kr,s

If r≠s: r!s! automorphisms. If r=s: 2(r!)2 automorphisms.

  1. Permute within parts. The two partite sets have sizes r and s; any permutation inside each part preserves all cross edges, giving r!s! automorphisms.
  2. Swap parts when possible. If r=s, exchanging the two parts is also an automorphism, doubling the count to 2(r!)2; for r=3 this is 2·62 = 72.
  3. Completeness. An automorphism must send partite sets to partite sets because adjacency within a part is uniformly absent, so no further maps exist.

Unlabelled graphs on 4 vertices

There are 11 isomorphism classes of simple graphs on 4 vertices, although there are 2C(4,2) = 26 = 64 labelled ones.

  1. Count labelled graphs. Six possible edges may each be present or absent, giving 64.
  2. Identify up to relabelling. Grouping the 64 by isomorphism yields 11 classes, a standard enumeration quoted from the lecture summary.

6. Worked examples

Example 1 (easy): degree sum with parallel edges

Take edges wx, wy, two copies of xy, and yz — five edges in all. Counting incidences: deg(w)=2 (wx, wy); deg(x)=3 (wx and two xy); deg(y)=4 (wy, two xy, yz); deg(z)=1. Sum = 2+3+4+1 = 10 = 2·5, confirming the handshaking lemma.

Example 2 (easy): the complete graph K4

Every pair of the 4 vertices is joined, so |E| = C(4,2) = 6. Each vertex has degree 3, sum = 4·3 = 12 = 2·6. Since all four vertices are pairwise adjacent, they need four different colours, so χ(K4)=4.

Example 3 (easy): counting graphs on four vertices

There are C(4,2)=6 possible edges, each independently present or absent, so 26=64 labelled simple graphs. Up to isomorphism these fall into 11 classes.

Example 4 (medium): the complete bipartite graph K3,3

Every one of the 3 vertices in the first part joins each of the 3 in the second, giving 3·3 = 9 edges and degree 3 at every vertex. It is bipartite by construction (one colour per part); it is non-planar, a standard result proved on page 15.

Example 5 (medium): an explicit isomorphism

Let G be the path with edges ab, bc, cd and H the path with edges xz, zy, yw. Define a↦x, b↦z, c↦y, d↦w. This is a bijection, and each G-edge maps to the corresponding H-edge: ab↦xz, bc↦zy, cd↦yw. Hence G≅H.

Example 6 (medium): a complement

Let V={a,b,c,d} and E(G)={ab,bc,cd}. The six possible edges are ab, ac, ad, bc, bd, cd, so E(Ḡ) = {ac,ad,bd}. Check the formula |E(G)|+|E(Ḡ)| = 3+3 = 6 = C(4,2), and degḠ(a)=2 = 3−degG(a)=3−1.

Example 7 (hard): a component bound

A graph with 8 vertices and 5 edges has at least 8−5 = 3 components. The bound need not be tight: if the 5 edges form a path on 6 vertices, the components are that path plus 2 isolated vertices, exactly 3; if they form a 5-cycle on 5 vertices, there are 4 components.

9. Common mistakes and exam traps

  1. Confusing walk, trail and path. Wrong: call a-b-c-a-b a path. Right: it is a walk that repeats vertex a and edge ab; a path such as a-b-c-d repeats no vertex.
  2. Under-counting a loop. Wrong: a loop adds 1 to the degree of its vertex. Right: it adds 2, so handshaking still gives an even degree sum; a single looped vertex has degree 2, not 1.
  3. Using a degree sequence to prove isomorphism. Wrong: conclude the two trees in section 8 are isomorphic because both have degree sequence 3,2,2,1,1,1. Right: their branch lengths at the degree-3 vertex are 1,1,2 and 1,2,2, so they are not isomorphic.
  4. Assuming n−1 edges force connectedness. Wrong: 4 vertices and 3 edges always give a connected graph. Right: a triangle on three vertices plus one isolated vertex has n=4, m=3 and is disconnected; n−1 is only a lower bound.
  5. Confusing maximal with maximum clique. Wrong: every maximal clique is a largest clique. Right: with a triangle 1-2-3 and an extra vertex 4 joined only to 1, the clique {1,4} is maximal of size 2, while the maximum clique {1,2,3} has size 3.
  6. Wrong complement degree. Wrong: degḠ(v) = n−degG(v). Right: there are only n−1 other vertices, so degḠ(v) = n−1−degG(v); in P4, degG(a)=1 gives complement degree 2, not 3.
  7. Double-counting Petersen edges. Wrong: 10 vertices of degree 3 give 30 edges. Right: each edge has two ends, so 10·3/2 = 15.

10. Practice questions (assigned to this page)

Q31. Prove that in any graph the number of odd-degree vertices is even.

Step 1. Every edge contributes two incidences, so Σv deg(v) = 2|E|, which is even.

Step 2. Split the sum into even-degree and odd-degree vertices. The even part is even, so the odd part is also even.

Step 3. A sum of odd integers is even only when there is an even number of terms, so the number of odd-degree vertices is even.

Q32. Give connected simple nonisomorphic graphs with the same degree sequence.

Step 1. Both trees drawn in section 8 have six vertices and edges {01,03,04,12,25} and {01,02,03,14,25} respectively. Both are connected, have 5 edges, and are therefore trees.

Step 2. In each, the degrees (at vertices 0,1,2,3,4,5) are 3,2,2,1,1,1, so the degree sequences agree.

Step 3. At the unique degree-3 vertex, the three branches have lengths 1,1,2 in the first tree and 1,2,2 in the second. Any isomorphism would preserve the degree-3 vertex and its branch lengths, so none exists. Brute-force enumeration over all 6! relabellings confirms the two are not isomorphic.

Q33. Prove that if every vertex has degree at least 2, then G contains a cycle.

Step 1. Take a longest path v0v1…vk; it exists because the graph is finite.

Step 2. The endpoint v0 has degree at least 2, so it has a neighbour other than v1.

Step 3. Every neighbour of v0 must lie on the path: otherwise the path could be extended at the front, contradicting maximality.

Step 4. Hence v0 is adjacent to some vi with i≥2, and v0v1…viv0 is a cycle. ∎

Q38. Prove that δ ≥ (n−1)/2 implies G is connected.

Step 1. Suppose G is disconnected, with components of sizes a1,…,ar, r≥2.

Step 2. A vertex in a component of size a has at most a−1 neighbours, so δ ≤ ai−1, giving ai ≥ δ+1 ≥ (n+1)/2.

Step 3. Two components would then contain at least n+1 vertices between them, contradicting the total of n. Hence r=1 and G is connected.

Q39. Prove that for a simple graph G, either G or its complement is connected.

Step 1. If G is connected there is nothing to prove, so assume G has components C1,…,Cr with r≥2.

Step 2. If u and v lie in different components, uv is not an edge of G, so it is an edge of the complement.

Step 3. If u,v lie in the same Ci, choose w in another component; by step 2 both uw and wv are complement edges, giving a complement path.

Step 4. Every pair is joined in the complement, so Ḡ is connected. ∎

11. Extra self-test questions

1. Check the handshaking lemma for K4.

All 4 vertices have degree 3, so the degree sum is 4·3 = 12. The graph has C(4,2)=6 edges, and 2·6 = 12. ✔

2. Minimum components for 8 vertices and 5 edges?

At least n−m = 8−5 = 3. Each edge can merge at most two components, so it is impossible to reach fewer than 3.

3. Petersen graph degree and edge count?

A vertex is a 2-subset of a 5-set; the disjoint 2-subsets of the remaining 3 elements number C(3,2)=3, so the degree is 3. By handshaking, edges = 10·3/2 = 15.

4. How many simple graphs on 3 labelled vertices?

There are C(3,2)=3 possible edges, each independently present or absent, giving 23 = 8 graphs.

5. Is K2,3 planar?

Yes. Not in slides - standard result. It has 5 vertices and 2·3 = 6 edges; a planar bipartite graph obeys e ≤ 2v−4 = 6, so the bound is tight and realisable: place the two partite vertices inside two of the three faces around a path through the three others. (K3,3, by contrast, is non-planar.)

6. How many edges has the path P4?

A path on n vertices has n−1 edges, so P4 has 3. Its two endpoints have degree 1 and its two internal vertices degree 2.

7. In P4 on vertices a-b-c-d, what is degḠ(a)?

With n=4 and degG(a)=1, the complement degree is n−1−degG(a) = 3−1 = 2 (the complement edges ac and ad).

8. How many automorphisms has K3,3?

Here r=s=3, so the count is 2(r!)² = 2·6² = 72: 3! permutations in each part, times 2 for swapping the equal-sized parts.

12. Cheat sheet

Definitions

  • Graph: vertex set V, edge set E, and an endpoint assignment for each edge.
  • Simple: no loops, no parallel edges; then E⊆C(V,2) and edges are unordered pairs.
  • Degree: number of incident edges; a loop contributes 2.
  • Walk / trail / path: repeats allowed / no repeated edges / no repeated vertices.
  • Connected: a path joins every pair; a component is a maximal connected subgraph.
  • Isomorphism: a vertex bijection preserving adjacency in both directions.
  • Complement: same vertices, uv present iff absent in G; degḠ(v)=n−1−degG(v).
  • Clique / independent set: pairwise adjacent / pairwise non-adjacent.

Theorems

  • Handshaking: Σ deg(v) = 2|E|; the number of odd-degree vertices is even.
  • Components ≥ n−m; connected ⇒ m ≥ n−1.
  • Every walk contains a path; connection is an equivalence relation with components as classes.
  • δ ≥ (n−1)/2 ⇒ connected; for any simple G, G or Ḡ is connected.
  • Petersen: 10 vertices, 15 edges, 3-regular, girth 5, diameter 2, vertex-transitive, non-planar.
  • Aut(Kr,s) = r!s! if r≠s, and 2(r!)² if r=s.
  • Labelled simple graphs on n vertices: 2C(n,2); unlabelled on 4 vertices: 11.

Exam checklist

  1. State whether loops or parallel edges are allowed before using simple-graph formulas.
  2. Count incidences with handshaking; loops count twice.
  3. Use degree sequences only as a quick invariant, never as proof of isomorphism.
  4. For connectivity, check the exact hypothesis (degree bound, complement, or edge count).
  5. Give a concrete invariant — cycles, branch lengths, bipartition — to prove non-isomorphism.
