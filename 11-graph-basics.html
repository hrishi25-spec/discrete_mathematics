11 Graph Basics

1. Why this topic matters

Graphs model relationships: bridges, networks, schedules, assignments. The basics (definitions, walks/paths, components, degree, isomorphism, Petersen graph) support every later graph topic. Exam questions often test definitions precisely and ask for short proofs like handshaking or connectivity.

2. Prerequisites

Set theory and counting from page 01 and page 02.

3. Intuition

A graph is a set of vertices plus edges connecting them. A walk can repeat; a trail cannot repeat edges; a path cannot repeat vertices. Components are the connected pieces. The picture below is a path on four vertices.

4. Definitions

Graph: vertex set V, edge set E, endpoint assignment.

Simple graph: no loops or multiple edges.

Degree: number of incident edges (loop counts 2).

Walk/trail/path/cycle: walk allows repeats; trail no repeated edges; path no repeated vertices; cycle closed path.

Connected: every pair has a path.

Component: maximal connected subgraph.

Isomorphism: bijection preserving adjacency both ways.

5. Theorems and complete proofs

Theorem: handshaking lemma

In any graph, the number of vertices of odd degree is even. Exam likely.

Proof. Sum of degrees = 2|E|, which is even. The sum of even-degree terms is even, so the sum of odd-degree terms must be even, requiring an even number of them. ∎

Theorem: components bound

A graph with n vertices and m edges has at least n-m components. Exam likely.

Proof. Start with n isolated vertices (n components). Each edge can reduce the component count by at most 1. After m edges, at least n-m components remain. ∎

Theorem: every walk contains a path

Every u,v-walk contains a u,v-path.

Proof. If a vertex repeats, delete the cycle between its two occurrences. This shortens the walk; repeat until no vertex repeats. ∎

Theorem: connection is an equivalence relation

u~v iff there is a u,v-path is an equivalence relation; its classes are components.

Proof. Reflexive via length-0 path; symmetric by reversing; transitive by concatenating walks and using the previous theorem. ∎

Theorem: connected graph edge minimum

A connected n-vertex graph has at least n-1 edges.

Proof. Components bound with c=1 gives 1≥n-m, so m≥n-1. ∎

Theorem: min degree connectivity

If simple graph G has minimum degree δ ≥ (n-1)/2, then G is connected. Exam likely (Q38).

Proof. If disconnected, take components A,B. For u∈A, deg(u)≤|A|-1; for v∈B, deg(v)≤|B|-1. Since |A|+|B|≤n, one of |A|-1, |B|-1 is < (n-1)/2, contradiction. ∎

Theorem: graph or complement connected

For any simple graph G, either G or its complement is connected. Exam likely (Q39).

Proof. If G disconnected, pick u,v in different components of G. In complement, u and v are adjacent (since not adjacent in G), and any two vertices in same G-component have a common non-neighbour? More directly, if G disconnected with components C_1,...,C_r, then in complement all C_i are cliques and every cross pair is adjacent, so complement is connected for r≥2. ∎

Theorem: Petersen graph properties

Petersen graph has 10 vertices, 15 edges, degree 3, girth 5, diameter 2, is vertex-transitive, non-planar. Exam likely.

Proof. Vertices are 2-subsets of a 5-set; adjacency is disjointness. Degree C(3,2)=3; edges=10*3/2=15. No triangle because three pairwise disjoint 2-subsets need 6 elements. Non-adjacent vertices have unique common neighbour, ruling out 4-cycles. A 5-cycle exists. ∎

Complements, cliques, and matrices

Complement: same vertices; uv is an edge iff it is not an edge in G.

Clique: pairwise adjacent vertices. Independent set: pairwise non-adjacent.

Adjacency matrix: A_{ij}=number of edges between v_i and v_j. Incidence matrix: M_{ij}=1 if v_i is endpoint of e_j.

Automorphisms of K_{r,s}

If r≠s: r!s! automorphisms. If r=s: 2(r!)^2 automorphisms.

9. Common mistakes and exam traps

  • Confusing walk, trail, and path.
  • Forgetting loops contribute 2 to degree.
  • Using degree sequence alone to prove isomorphism.
  • Thinking n-1 edges guarantee connectedness.
  • Confusing maximal clique with maximum clique.

10. Practice questions (assigned to this page)

Q31. Prove that in any graph, number of odd-degree vertices is even.

Solution: handshaking lemma proof above.

Q32. Give connected simple nonisomorphic graphs with same degree sequence.

Solution: two nonisomorphic trees with degree sequence 3,2,2,1,1,1 (for example, a star K1,3 with a path attached in two different ways).

Q33. Prove if every vertex has degree at least 2, then G contains a cycle.

Solution: take a maximal path; its endpoint has a neighbor on the path, forming a cycle.

Q38. Prove if δ≥(n-1)/2 then G is connected.

Solution: proof above.

Q39. Prove for simple graph and complement, at least one is connected.

Solution: proof above.
